# 岛工坊 Isle Works - 游戏设计文档

## 功能目标
玩家在有限面积的漂浮小岛上自由建造工厂产线，扩岛、解锁、优化，追求极致空间利用率。

## 范围边界
### 我们做
- 小岛布局的自由建造和规划。
- 通过资源采集、加工和出口形成循环。
- 引入科技树和多样化产线，增加战略选择。
- 提供美术表现和动画以凸显工业动态。

### 我们不做
- 实时战斗或PVP系统。
- 玩家直接控制角色行为。
- 复杂的经济模拟（如动态市场波动）。

## 核心设计
### 核心循环
1. **资源采集**：从岛屿资源点收集基础材料，如矿石、木材。
2. **加工和制造**：利用机器将资源转化为产品。
3. **产品出口**：通过港口或商船出售产品以获取金币。
4. **岛屿扩展**：购买或解锁新岛屿区域，探索未知资源。
5. **科技升级**：解锁更高级的机器、产线组件和生产能力。
6. **优化和布局**：在有限空间内最大化生产力。

### 网格系统
1. **格子尺寸**：默认网格以 1×1 单位为基础。
2. **机器占位**：普通设备单占 1×1，高级设备（如组合机）占用更大的 2×2 区域。
3. **传送带规则**：
   - 传送带只能单向运输，每条路径需要规划终点，否则可能堵塞。
   - 出现堵塞时，资源会堆积在传送带上，超过容量时设备会停机。
4. **布局限制**：
   - 地形限制在初始阶段固定，需通过科技研究或工具改造（如填海、挖山）才能进一步扩展或改造。
   - 提供网格化路径规划工具，方便玩家实时调整线路布局。
### 数值框架
- **资源产量关系**：不同资源节点的采集效率呈现线性成长，科技解锁后会趋向指数增长，避免过早达到高产量。
- **加工效率趋势**：加工设备按照递增效率效果设定，如基础加工显著提升资源数量，高级加工逐步向高复杂性资源过渡。
- **经济曲线**：产品价格根据加工链路长度与复杂性计算递增，设置“递减收益”惩罚以防止单一资源循环。
- **扩岛曲线**：地块价格逐步增加，后期新增地块的成本递增更快。
### 机器列表
#### 初始解锁
- **采矿机**：采集基础资源（矿石、石头）。
- **传送带**：用于连接机器，自动运输资源/产品。
- **冶炼炉**：将矿石加工为金属锭。
- **木材加工机**：将木材转化为木板。
#### 高级解锁
- **组合机**：将两种原料合成中级部件（如铜锭+木板=电路板）。
- **高速传送带**：提升单位时间的运输速度。
- **自动存储仓库**：扩展存储容量并增加自动堆叠逻辑。
- **发电站**：生产能量供电给高级机器。

### 资源链路
资源链路将采用网状结构，最少包括如下：

**基础资源**：
1. 木材（森林） → 木板，加工后可作为燃料或建筑材料。
2. 矿石（石矿） → 金属锭（加工获得）。
3. 煤炭（煤矿） → 提供基础燃料，也可用于冶炼。
4. 水（河流/湖泊） → 用于冷却或化工合成。
5. 石油（油井） → 化工原料，用于制作塑料等。

**加工链路**：
- 木材 + 矿石 → 组合机 → 简单工具（用于建筑）。
- 金属锭 + 塑料 → 精密设备（提升机器运转效率）。
- 煤炭 + 水 → 化学反应装置 → 生成新型燃料。

**深度加工链路**：
- 高级电路板（由铜板 + 塑料制成）嵌入到智能设备。
- 高效燃料（多种材料混合）提供给发电站或高级设备。
- 最终制成品（自动化装置）需求最高复杂度链路，将是后期高收益领域。
### 时代解锁详情
#### 石器时代
- 初始科技，解锁采矿机、冶炼炉。
- 没有动态环境或资源耗竭。
#### 铜器时代
- 解锁组合机和基础电路板制造。
- 扩岛开始涉及较高消耗。
#### 蒸汽时代
- 引入能源概念，需建造蒸汽发电站。
- 高级传送带可提升物流效率。
#### 电气时代
- 解锁全自动化逻辑，例如智能分拣机。
- 科技点影响生产效率，加入订单和时间强化机制。
### 驱动力设计
- **里程碑解锁**：达到阶段性产出目标，触发时代升级，同时激活新机制。
- **扩岛探索**：获得新地块解锁更稀有的资源（地块随机生成）。
- **订单系统**：平台不时发布高价订单，玩家可选择是否完成。
- **装饰与创意**：玩家可以设计独特布局以展示创意。

### 岛屿地形
1. **地形分类**：
   - 普通地块：可自由放置设备。
   - 水域：初始无法直接建造，需填海完成改造。
   - 石地块：含高矿藏，但无法种植农田作物。
2. **特殊限制**：
   - 复杂地形区域（山地或灌木丛）需消耗金币和时间清理。
   - 地块间连接性会影响运输效率。
3. **视觉表现**：通过地形高度差与水流动画模拟生动环境。

### 拆除与重建
1. **拆除规则**：允许玩家移除已建造建筑，返还部分成本资源。
2. **重建规则**：
   - 玩家可覆盖低级建筑部署高级设备（需额外费用）。
   - 迁移功能需要科技解锁，允许完整保留建筑并移动至新位置。
### 游戏规则
- 每个设备有固定操作范围，合理放置位置影响效率。
- 地块解锁需要金币，每块地块初期属性随机。

## 验收条件
- 玩家可完成一轮完整的核心循环（资源采集、加工、出口、扩岛）。
- 支持多个类型的科技解锁并对生产力产生明显提升。
- 引导玩家进行产线布局优化，逐步感受空间压力。
