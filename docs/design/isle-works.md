# 岛工坊 Isle Works - 游戏设计文档

## 功能目标
在漂浮岛屿的有限空间内，玩家通过采集资源、优化产线和布局工厂的方式，扩岛、解锁新技术和设备，追求最高生产效率和岛屿布局的美感。

## 范围边界
### 我们做
- 强调自由建造和空间优化的沙盒玩法。
- 多时代技术演进，逐步产生新玩法机制和挑战。
- 视觉化动态物流系统（传送带、产线设备）。
- 有战略深度的网格布局和地块规划。
- 随机性地块扩展，使每次游戏都有独特体验。

### 我们不做
- 实时战斗或直接竞争玩法。
- 深度经济模拟（复杂市场或需求体系）。
- 高复杂的物理引擎。

## 核心设计
### 核心循环
1. **资源采集**：从基础的地块节点采集面向生产的资源（如矿石、木材）。
2. **产线建造与优化**：通过放置采矿机、加工台、传送带，形成不同深度和交叉的资源网链。
3. **产品出口**：把最终产品卖出，获取金币。
4. **经济循环**：
   - **产品销售**：价格基于资源的加工深度和稀有度成非线性增长。
     - 基础资源售价 = 原料成本 × 1.0。
     - 中间产品售价 = 基础资源售价 × 加工深度系数。
     - 高级产品售价 = 加工深度 × 稀有度 × 复杂度系数。
   - **金币用途**：扩岛、购买新机器、解锁科技节点。
   - **收支曲线**：前期紧张（快速扩岛和资源收集成本较高），中期过渡（机器效率提升，带来盈收缓解），后期宽松（高端产品售出利润大）。
5. **岛屿扩展**：解锁和购买新地块，探索未知资源与挑战。
6. **技术升级**：研究新技术，解锁更高效的设施、更复杂的产线组件。
7. **布局重组**：面对更多限制与目标，优化已有布局。

### 网格系统
1. **格子尺寸与规则**：
   - **初始岛**：建议尺寸为 8×8。
   - 每格默认尺寸：1×1 单位。
   - 普通机器占 1×1（如采矿机）；高级机器占 2×2（如复杂组合机）。
 
2. **扩岛费用**：
   - 扩岛费用呈指数增长，确保玩家具备长线规划意识。
 
3. **传送带规则与堵塞机制**：
   - 单向输送，每条传送带需要明确起点和出口，否则资源堆积。
   - 堆满状态会向前传播堵塞，最终导致设备停机。
   - 智能分拣机可在电气时代解锁，实现多路径拆分。

### 资源体系设计
#### 资源种类与深度
- 基础资源：
   1. 木材 → 加工为木板，用于初期建筑燃料和结构件。
   2. 矿石 → 冶炼为金属锭。
   3. 煤炭 → 提供初级燃料，也能参与高级化工。
   4. 水 → 用于冷却、参与化学反应。
   5. 石油 → 合成塑料和化工产品的重要原料。

- 多层资源链路：
   - **浅层加工**：木材 → 木板，矿石 → 金属锭。
   - **中间加工**：
     - 金属锭 + 木板 → 简单工具。
     - 塑料 + 锭 → 电路板；电路板是多种高级设备的关键件。
   - **深加工终端**：最终生产如自动化装置，需高度复杂资源组合。

### 岛屿扩展与地形
1. **地块类型**：
   - 普通地块：开局区域，可自由建设。
   - 水域：需填海或建桥方可使用。
   - 山地：需耗费额外资源平整或通过解锁采矿机挖掘。
2. **随机探索**：每次扩岛揭示周边迷雾，增加不可预测性。

### 时代与新机制
1. **石器时代**（初始）：基本设备，无能源和动态压力。
2. **铜器时代**：
   - 新机制：多输入合成，部分机器需要两种以上资源输入，带来新布局挑战。
   - 解锁初级燃料与组合机。
3. **蒸汽时代**：加入能源网络，需要协调供需。
4. **电气时代**：解锁智能分拣和复杂路径逻辑。

### 长期驱动力
1. **蓝图功能**：允许保存复杂生产线布局供未来复用或与其他玩家分享。
2. **成就系统**：设置挑战性目标，例如极限产量、最少布局完成目标等。
3. **多岛存档**：支持玩家同时管理多个岛屿档案。
4. **排行榜**：加入全球或好友优化排行，激励极限效率优化。

### 拆除与布局重建
1. 拆除规则：返还一部分资源。
2. 覆盖或升级：允许高阶建筑直接覆盖旧有设施，收回部分材料。

## 验收条件
1. 玩家可完成至少一次完整核心循环（采集 → 加工 → 出口 → 扩岛）。
2. 设计体现出空间和布局优化的压力。
3. 资源链路达到网状结构（多条产线共享资源）。
4. 每个时代解锁的新机制能显著影响玩法与布局。
