# Off Trail（离径）— 游戏设计文档

## 1. 游戏概述

### 核心定位
北方针叶林荒野独居生存游戏。玩家从一无所知开始，通过探索、试错、观察逐步解锁生存知识，从艰难求生走向自在独居。

### 核心体验
- **宁静**：不是恐怖生存，而是与自然共处的沉浸感
- **自由**：没有强制任务线，玩家自己决定每天做什么
- **从无到有的成就感**：从喝生水到拥有完整木屋和壁炉

### 参考
- 荒野独居（Alone）节目的日常节奏
- Don't Starve 的探索与发现
- Stardew Valley 的温暖像素风

### 边界（不做）
- 不做战斗系统（野兽是环境威胁，不是战斗对象）
- 不做多人联机
- 不做复杂物理模拟
- 不做恐怖/血腥元素

## 2. 核心系统

### 2.1 知识系统（Knowledge System）

玩家初始只有最基础能力（移动、拾取、喝溪水）。所有技能和配方都需要通过**发现**来解锁。

#### 知识解锁方式

| 方式 | 说明 | 举例 |
|------|------|------|
| 物品触发 | 同时拥有特定物品组合 | 燧石 + 干草 → 解锁"生火" |
| 试错学习 | 使用/食用未知物品 | 吃未知浆果 → 记录安全/有毒 |
| 观察发现 | 到达特定地点或观察现象 | 发现动物足迹 → 解锁"追踪" |
| 组合实验 | 在工作台尝试组合材料 | 粘土 + 火 → 解锁"烧陶" |

#### 知识类别与进阶路线

```
火与热
  L1 生火（燧石+干草）
  L2 火堆维护（持续添柴保持火焰）
  L3 烟熏保存（用烟熏肉/鱼延长保质期）
  L4 木炭烧制（将木材烧成木炭，更高效燃料）
  L5 锻造炉（石头砌炉 + 木炭 → 可以炼铁）

水与食
  L1 溪水饮用（直接喝，有概率生病）
  L2 净水（陶碗 + 水 + 火 → 烧开水）
  L3 植物辨识（逐一记录可食用/有毒植物）
  L4 陷阱制作（绳索 + 木棍 → 小型猎物陷阱）
  L5 钓鱼（鱼钩 + 线 + 木杆 → 钓竿）
  L6 简单种植（收集种子 + 翻土 → 小菜园）

居所
  L1 树下避雨（找大树暂时躲避）
  L2 简易窝棚（树枝 + 树叶 → 最基础遮风挡雨）
  L3 木屋框架（原木 + 绳索 → 结构框架）
  L4 完整木屋（框架 + 木板 + 屋顶 → 可居住）
  L5 壁炉（石头 + 粘土 → 室内取暖 + 烹饪）

工具
  L1 石器（石头 + 木棍 → 石斧/石刀）
  L2 骨器（动物骨头加工 → 骨针/骨钩）
  L3 绳索编织（植物纤维/树皮 → 绳索）
  L4 木工（石斧 + 原木 → 木板/木桩）
  L5 铁器（铁矿 + 锻造炉 + 木炭 → 铁刀/铁斧）

容器
  L1 树皮碗（剥树皮 → 临时容器）
  L2 烧制陶器（粘土 + 火 → 碗/罐）
  L3 编织篮筐（柳条/藤蔓 → 采集篮）
  L4 木桶（木板 + 绳索 → 储水/储物）
```

#### 知识本 UI
玩家拥有一本"知识本"，记录已发现的所有知识。未发现的知识显示为锁定状态，不提供任何提示。已发现但未完全掌握的知识显示为模糊状态。

### 2.2 生存系统（Survival System）

四项基础状态，每项 0-100：

| 状态 | 下降方式 | 补充方式 | 归零后果 |
|------|---------|---------|---------|
| 饱食度 | 随时间持续下降，劳动加速消耗 | 进食 | 体力无法恢复，持续掉血 |
| 口渴度 | 随时间下降，比饥饿更快 | 饮水 | 快速掉血 |
| 体温 | 受天气/衣物/火源影响 | 靠近火源/穿衣/进入庇护所 | 冻伤减速，持续掉血 |
| 体力 | 劳动消耗（砍树、挖掘、建造等） | 休息/睡觉 | 无法执行劳动动作 |

#### 天气与季节

| 季节 | 特点 | 挑战 |
|------|------|------|
| 春 | 万物复苏，适合采集，偶尔降雨 | 食物来源刚恢复，储备不足 |
| 夏 | 资源丰富，天气温暖 | 食物容易腐烂，需要烟熏保存 |
| 秋 | 浆果丰收，树叶变色，气温下降 | 必须为冬天储备 |
| 冬 | 极寒，降雪，植物枯萎 | 生存核心挑战，需要庇护所+火+储备食物 |

每季 7 天，一年 28 天。每天分为：黎明、白天、黄昏、夜晚四个时段。

#### 昼夜循环
- 白天（黎明+白天+黄昏）：探索、采集、建造
- 夜晚：需要庇护所和火光，否则体温急剧下降

### 2.3 制作系统（Crafting System）

玩家只能制作已通过知识系统解锁的配方。

#### 制作方式

| 方式 | 说明 |
|------|------|
| 手工制作 | 随时可做，简单物品（绳索、石器等） |
| 火堆制作 | 需要在点燃的火堆旁（烧陶、烹饪、烟熏） |
| 工作台制作 | 需要建造工作台（木工制品、复杂工具） |
| 锻造炉制作 | 需要建造锻造炉（铁器、金属制品） |

#### 物品分类

| 分类 | 举例 |
|------|------|
| 原材料 | 木头、石头、粘土、铁矿、植物纤维、动物皮毛 |
| 食物 | 浆果、蘑菇、鱼、兔肉、烤肉、干粮 |
| 工具 | 石斧、石刀、鱼钩、铁斧、铁刀 |
| 容器 | 树皮碗、陶碗、陶罐、篮筐、木桶 |
| 建材 | 原木、木板、绳索、石砖 |
| 消耗品 | 干草（引火）、木柴、木炭、草药 |

### 2.4 世界系统（World System）

#### 地图结构
以玩家初始位置为中心，世界由多个**区域**（Region）组成，需要探索才能揭开：

| 区域 | 资源 | 特点 |
|------|------|------|
| 营地（起始点） | 小片空地 | 安全区域，适合建造 |
| 松林 | 木材、松脂、蘑菇 | 最大区域，木材主要来源 |
| 溪谷 | 鱼、粘土、饮用水、柳条 | 水源地，粘土用于烧陶 |
| 岩坡 | 石头、燧石、铁矿 | 地形陡峭，矿物资源 |
| 沼泽 | 草药、泥炭、浆果 | 行动缓慢，特殊植物 |
| 白桦林 | 桦树皮、浆果、小动物 | 秋季浆果丰收 |
| 山脊 | 视野开阔、特殊石材 | 高处可以俯瞰全图 |

#### 资源再生
- 树木：砍伐后缓慢再生（数天）
- 浆果/蘑菇：每季刷新
- 鱼：每天刷新
- 矿石：不再生（有限资源）
- 动物：缓慢再生

## 3. 游戏节奏

### 第一天体验（教学）
1. 醒来在空地上，什么都没有
2. 四处走动，发现可拾取物品（石头、树枝）
3. 口渴了 → 找到溪流 → 喝水（但有概率不适）
4. 饿了 → 捡起地上的浆果 → 吃（发现哪些可食用）
5. 拾取燧石 + 干草 → 触发"生火"知识解锁
6. 第一次生火 → 核心成就感
7. 天黑了 → 找大树下蹲着过夜（体温下降但不至于死）
8. 第二天目标自然浮现：建一个窝棚

### 中期体验（第 7-14 天）
- 已有简易窝棚和稳定火源
- 开始学习陷阱和钓鱼
- 尝试烧制第一个陶碗
- 为即将到来的冬天做准备

### 后期体验（第 21 天+）
- 拥有完整木屋和壁炉
- 有储备食物和工具
- 开始追求更舒适的生活（铁器、种植）
- 享受宁静的独居生活

## 4. 技术架构

### 保留的框架层
- JulyArch：Store/System/View 架构
- JulyCore：Resource、UI、Scene、Audio、Save、Config、Localization、Input、Time、Pool、Fsm 模块
- HybridCLR：热更新
- Luban：数据管线
- YooAsset：资源管理
- URP 2D Renderer

### 新游戏模块

| 模块 | Store | System | View |
|------|-------|--------|------|
| 生存 | SurvivalStore | SurvivalSystem | SurvivalHUD |
| 知识 | KnowledgeStore | KnowledgeSystem | KnowledgeBookWindow |
| 制作 | InventoryStore | CraftingSystem | CraftingWindow |
| 世界 | WorldStore | WorldSystem | WorldView |
| 时间 | TimeStore | DayNightSystem | TimeHUD |

### Luban 配置表

| 表名 | 用途 |
|------|------|
| tbitem | 物品定义（ID、名称、类型、堆叠上限、描述） |
| tbrecipe | 制作配方（需要材料、产出、制作方式、耗时） |
| tbknowledge | 知识条目（ID、类别、等级、解锁条件、解锁配方列表） |
| tbregion | 区域定义（ID、名称、资源分布、进入条件） |
| tbcraftstation | 工作台定义（ID、名称、可用配方列表） |

## 5. 美术风格

**像素风（Pixel Art）**，温暖自然色调。

- 色板：森林绿、松木棕、溪水蓝、岩石灰、篝火橙
- 参考：Stardew Valley 的温暖感 + Don't Starve 的荒野氛围
- UI：木质/自然风像素 GUI
