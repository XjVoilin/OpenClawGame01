# Off Trail（离径）— 游戏设计文档

## 1. 游戏概述

### 核心定位
北方针叶林荒野独居生存游戏。玩家从一无所知开始，在完全自由的世界中通过探索、试错、观察逐步积累生存经验，从艰难求生走向自在独居。

### 核心体验
- **宁静**：不是恐怖生存，而是与自然共处的沉浸感
- **自由**：没有强制任务线，玩家自己决定每天做什么
- **从无到有的成就感**：从喝生水到拥有完整木屋和壁炉

### 参考
- 荒野独居（Alone）节目的日常节奏
- Don't Starve 的探索与发现
- Stardew Valley 的温暖像素风

### 边界（不做）
- 不做战斗系统（野兽是环境威胁，不是战斗对象）
- 不做多人联机
- 不做复杂物理模拟
- 不做恐怖/血腥元素

## 2. 核心系统

### 2.1 知识系统（Knowledge System）

知识系统是**指南针而非门锁**——玩家从头到尾都可以自由尝试世界中的一切操作，知识的作用是**提供线索和指引**，降低试错成本。没有任何操作被知识"锁住"，玩家完全可以在没有相关知识的情况下误打误撞做出同样的事。

#### 设计原则
- **自由优先**：所有交互操作永远开放，不存在"解锁才能做"
- **知识即指引**：点亮知识后，告诉玩家材料在哪、条件是什么、怎么做效率更高
- **试错有回报**：玩家的每次尝试（无论成功失败）都有可能积累经验、触发知识记录

#### 知识获取方式

| 方式 | 说明 | 举例 |
|------|------|------|
| 成功实践 | 成功完成某个操作后自动记录 | 第一次成功生火 → 记录"生火"知识 |
| 试错积累 | 反复尝试某类操作积累经验 | 多次尝试不同浆果 → 逐步记录哪些可食用 |
| 观察发现 | 到达特定地点或观察自然现象 | 发现溪谷红色泥巴 → 记录"含铁泥土"线索 |
| 偶然触发 | 意外的操作结果带来新认知 | 木材在高温火堆中变黑 → 记录"木炭"知识 |

#### 知识点亮后提供的指引

知识被点亮后，不是给玩家"许可"，而是给玩家**具体的线索**：

| 指引类型 | 说明 | 举例 |
|----------|------|------|
| 材料产地 | 标注材料在地图上的大致位置 | "溪谷东侧的红色泥巴含铁量高" |
| 操作条件 | 提示需要什么条件才能成功 | "需要锻造炉达到高温状态" |
| 操作步骤 | 记录成功时的操作流程 | "将含铁泥土放入高温锻造炉，等待冶炼" |
| 进阶提示 | 暗示更深层的可能性 | "木炭比普通木柴能达到更高温度" |

#### 知识类别参考路线

以下是玩家可能的知识积累方向，但不是强制的线性路径——玩家可以以任何顺序获取任何知识：

```
火与热
  摩擦生火（弓钻法/燧石+干草 → 引燃）
  火堆维护（燃料三级：引火物→细枝→粗柴，针叶木快燃/硬木持久）
  烟熏保存（烟熏架+湿木阴燃产烟 → 熏肉/熏鱼可存数月）
  木炭烧制（土窑闷烧法，观察烟色判断进度：白烟→蓝烟→封死）
  锻造炉（黏土圆柱炉+木炭+风箱鼓风 → 1200°C冶炼沼铁矿）

水与食
  溪水饮用（流水比死水安全，泉眼水最佳，但都有腹泻风险）
  净水（煮沸法/石煮法/木炭+沙子分层过滤后煮沸）
  植物辨识（蓝莓安全、白色浆果有毒、松针茶防坏血病、桦树汁可饮）
  陷阱制作（套索陷阱放在动物跑道上/压落式"四"字形触发+重石）
  钓鱼（骨钩+纤维线+柳枝竿/鱼叉/柳条鱼笼/石堰引流）
  简单种植（春播秋收，溪边沃土+草木灰施肥，需篱笆防动物）

居所
  树下避雨（大云杉树冠遮蔽+落叶铺垫隔绝地面寒气）
  碎屑棚（脊梁杆+树枝框架+60cm厚碎屑保温层，类似全身睡袋）
  斜靠棚（单面斜墙+前方长火堆取暖，快速搭建但保温有限）
  原木木屋（圆木叠摞+凹槽互锁+苔藓泥巴填缝密封）
  壁炉（石砌火箱+烟囱排烟，需要合适石材和黏土黏合剂）

工具
  石器打制（燧石打击剥片→粗加工，骨/角压力剥片→精修刃口）
  骨器加工（腿骨磨制→骨针/骨钩/骨锥，鹿角→锄/耙）
  绳索编织（树皮/荨麻纤维反向缠绕法，筋腱绳最强韧）
  木工（石楔/木楔沿木纹劈板，铁斧效率远高于石斧）
  铁器锻造（铁块反复加热锤打去渣→成型→淬火硬化）

容器
  桦树皮容器（春季剥皮+云杉根缝合+树脂密封，装水可上火）
  烧制陶器（溪谷黏土+砂混合→泥条盘筑成型→彻底晾干→坑烧法）
  编织篮筐（柳条/藤蔓泡软→辐射骨架+交替编纬→收口折编）
  木桶（粗木掏空法：火烧+斧刮交替/桶板拼合+绳箍）

皮革与保暖 [新增]
  脑鞣制皮（刮脂脱毛→脑液浸泡→持续拉伸晾干→硬木烟熏防水）
  毛皮处理（保留毛发的简易处理→骨针+筋线缝合衣物）

天然粘合 [新增]
  桦树皮焦油（露天凝结法：燃烧桦树皮→焦油凝结在冷石面→刮取）
  松脂胶（松脂+木炭粉小火融合，易获得但强度略低于桦树皮焦油）

狩猎与防御 [新增]
  简易弓（桦木削制D形截面弓身+筋腱弓弦+石/骨箭头）
  矛与投矛器（木杆火烤硬化尖端/绑石尖+投矛器增加射程）

草药与急救 [新增]
  伤口处理（泥炭藓压迫止血+蓍草消炎+烧开水清洗+松脂防感染）
  药用植物（松针茶防坏血病、桦树内皮止痛退烧、蓍草止血退烧）
```

> 每个技能点的真实原理、操作细节、游戏化转译和野外笔记文本详见 [survival-knowledge-reference.md](survival-knowledge-reference.md)。

#### 野外笔记 UI
玩家拥有一本"野外笔记"，以手绘涂鸦风格记录玩家的所有发现和经验：
- **空白**：玩家尚未接触过的领域，笔记中没有相关页面
- **模糊记录**：玩家尝试过但未完全成功，笔记中出现潦草的图示和问号
- **完整记录**：玩家成功实践过，笔记中记录详细步骤、材料产地标注、操作条件提示

### 2.2 生存系统（Survival System）

四项基础状态，每项 0-100：

| 状态 | 下降方式 | 补充方式 | 归零后果 |
|------|---------|---------|---------|
| 饱食度 | 随时间持续下降，劳动加速消耗 | 进食 | 体力无法恢复，持续掉血 |
| 口渴度 | 随时间下降，比饥饿更快 | 饮水 | 快速掉血 |
| 体温 | 受天气/衣物/火源影响 | 靠近火源/穿衣/进入庇护所 | 冻伤减速，持续掉血 |
| 体力 | 劳动消耗（砍树、挖掘、建造等） | 休息/睡觉 | 无法执行劳动动作 |

#### 天气与季节

| 季节 | 特点 | 挑战 |
|------|------|------|
| 春 | 万物复苏，适合采集，偶尔降雨 | 食物来源刚恢复，储备不足 |
| 夏 | 资源丰富，天气温暖 | 食物容易腐烂，需要烟熏保存 |
| 秋 | 浆果丰收，树叶变色，气温下降 | 必须为冬天储备 |
| 冬 | 极寒，降雪，植物枯萎 | 生存核心挑战，需要庇护所+火+储备食物 |

每季 7 天，一年 28 天。每天分为：黎明、白天、黄昏、夜晚四个时段。

#### 昼夜循环
- 白天（黎明+白天+黄昏）：探索、采集、建造
- 夜晚：需要庇护所和火光，否则体温急剧下降

### 2.3 制作系统（Crafting System）

制作系统采用**站点交互**模式：没有传统的配方菜单，玩家通过将物品放入交互站点来触发转化。底层由配方表驱动，但玩家体验是自由实验。

#### 核心交互流程
1. 玩家将物品**放入**交互站点（火堆、锻造炉、工作台等）
2. 系统根据放入的物品组合 + 站点状态（温度等级等）查询配方表
3. 条件满足 → 经过一段时间后产出结果物品
4. 条件不满足 → 给出部分反馈或无反应

#### 交互站点

| 站点 | 操作方式 | 可变条件 | 举例 |
|------|---------|---------|------|
| 地面/手持 | 直接组合手中物品 | 无 | 石头+木棍→石斧，植物纤维→绳索，骨头+磨石→骨针 |
| 火堆 | 将物品放在火堆上/旁 | 火焰强度（微火/中火/旺火） | 粘土+旺火→陶碗，肉+中火→烤肉，桦树皮+火→焦油凝结在旁边石头上 |
| 工作台 | 将物品放上工作台操作 | 是否有工具辅助 | 原木+石斧→木板，桦木+刀→弓身 |
| 锻造炉 | 将物品放入炉中 | 炉温等级（需要木炭+鼓风维持高温） | 含铁泥+高温→铁块，铁块+锤打→铁器 |
| 烟熏架 | 将食物挂在烟熏架上 | 需要持续的烟（火堆+湿木） | 生鱼+烟熏→熏鱼，鞣制皮→烟熏皮革 |
| 土窑 | 将木材填入封闭土窑 | 通风口开闭状态 | 木材+封闭闷烧→木炭 |
| 水边 | 在溪流/水源旁操作 | 水流强度 | 树皮浸泡沤麻→纤维，生皮浸泡脱毛 |

#### 反馈系统

玩家的每次尝试都应该得到有意义的反馈，引导试错方向：

| 反馈等级 | 表现 | 含义 |
|----------|------|------|
| 成功 | 物品转化动画 + 音效 + 产出新物品 | 组合正确，条件满足 |
| 接近成功 | 部分反应（冒烟、变色、发出声响）但未转化 | 方向对了，但条件不足（如温度不够） |
| 无效 | 物品被消耗/烧毁，无产出 | 组合完全不搭 |
| 无反应 | 物品原样取回 | 该站点不接受此类物品 |

#### 物品分类

| 分类 | 举例 |
|------|------|
| 原材料 | 木头、石头（燧石/石英/普通）、黏土、含铁泥土、植物纤维、荨麻、动物皮毛、筋腱、骨头、鹿角 |
| 食物 | 浆果（蓝莓/未知浆果）、蘑菇（鸡油菌/毒蝇伞等）、鱼、兔肉、烤肉、熏肉、干粮、桦树汁 |
| 工具 | 石斧、石刀、骨针、骨钩、骨锥、鱼竿、弓、箭、矛、铁斧、铁刀、铁锤 |
| 容器 | 桦树皮碗、陶碗、陶罐、篮筐、鱼笼、木桶 |
| 建材 | 原木、木板、绳索（树皮/纤维/筋腱）、石砖、苔藓（填缝） |
| 燃料与消耗品 | 干草（引火）、桦树皮丝（引火）、木柴（软木/硬木）、木炭、松脂 |
| 粘合剂 | 桦树皮焦油、松脂胶 |
| 皮革与衣物 | 生皮、鞣制皮革、毛皮、皮衣、皮靴、手套 |
| 草药 | 蓍草（止血消炎）、松针（泡茶防坏血病）、桦树内皮（止痛退烧）、泥炭藓（敷料） |

### 2.4 世界系统（World System）

#### 地图结构
以玩家初始位置为中心，世界由多个**区域**（Region）组成，需要探索才能揭开：

| 区域 | 资源 | 特点 |
|------|------|------|
| 营地（起始点） | 石头、树枝、干草 | 安全区域，适合建造 |
| 松林 | 木材、松脂、松针、蘑菇、树皮纤维 | 最大区域，木材/松脂/木炭原料来源 |
| 溪谷 | 鱼、黏土、饮用水、柳条、含铁红泥、河卵石 | 水源地，黏土烧陶，红泥炼铁 |
| 岩坡 | 燧石、石英、铁矿石 | 地形陡峭，石器和高品位矿石来源 |
| 沼泽 | 泥炭藓、蓍草、浆果、泥炭、荨麻 | 行动缓慢，草药和纤维来源 |
| 白桦林 | 桦树皮、桦树汁、浆果、小动物、桦木 | 桦树皮容器/焦油/引火物，制弓木材 |
| 山脊 | 视野开阔、特殊石材、鹿角 | 高处俯瞰全图，骨器/投矛器材料 |

#### 资源再生
- 树木：砍伐后缓慢再生（数天）
- 浆果/蘑菇：每季刷新
- 鱼：每天刷新
- 矿石：不再生（有限资源）
- 动物：缓慢再生

## 3. 游戏节奏

### 第一天体验（教学）
1. 醒来在空地上，什么都没有
2. 四处走动，发现可拾取物品（石头、树枝、干草）
3. 口渴了 → 找到溪流 → 喝水（但可能不适）
4. 饿了 → 捡起地上的浆果 → 吃（有些好吃，有些让人肚子疼）
5. 尝试把燧石和干草凑在一起摆弄 → 冒出火星 → 第一次生火！
6. 野外笔记自动记录了生火的方法，并提示"干草越干燥越容易点燃"
7. 好奇地把捡到的蘑菇放在火边 → 蘑菇变色散发香味 → 烤蘑菇！
8. 天黑了 → 找大树下蹲着过夜（体温下降但不至于死）
9. 第二天目标自然浮现：建一个窝棚

### 中期体验（第 7-14 天）
- 已有简易窝棚和稳定火源
- 开始学习陷阱和钓鱼
- 尝试烧制第一个陶碗
- 为即将到来的冬天做准备

### 后期体验（第 21 天+）
- 拥有完整木屋和壁炉
- 有储备食物和工具
- 开始追求更舒适的生活（铁器、种植）
- 享受宁静的独居生活

## 5. 美术风格

**像素风（Pixel Art）**，温暖自然色调。

- 色板：森林绿、松木棕、溪水蓝、岩石灰、篝火橙
- 参考：Stardew Valley 的温暖感 + Don't Starve 的荒野氛围
- UI：木质/自然风像素 GUI
