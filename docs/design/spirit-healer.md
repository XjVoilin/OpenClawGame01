# 灵药师（Spirit Healer）— 游戏设计文档

## 1. 游戏概述

### 核心定位
修仙世界山间药庐经营模拟。玩家扮演一位隐居灵山的灵药师，通过望闻问切理解万物，种药采药、辨证开方、悬壶济世，在精进医术的过程中感受修仙世界的宁静与奇遇。

### 核心体验
- **精进**：从看不懂脉象到一眼识破疑难杂症，从种凡草到培育仙药，每一步成长都有实感
- **济世**：每一个来客都带着他的故事和困境，你的处方改变他们的命运
- **宁静**：没有打打杀杀，只有晨起巡田、午后接诊、暮色煎药的山间日常

### 参考
- 修仙小说中炼丹/药师相关情节（药性相生相克、丹方发现、奇遇机缘）
- Potion Craft 的实验发现乐趣
- Strange Horticulture 的辨识与推理
- 了不起的修仙模拟器的修仙世界氛围

### 边界（不做）
- 不做战斗系统（修仙世界有冲突，但玩家不参与战斗）
- 不做大世界探索（活动范围限于药庐及周边小区域）
- 不做境界修炼/飞升（玩家是医者，不走战斗修炼路线）
- 不做多人联机

## 2. 核心系统

### 2.1 望闻问切系统（Diagnosis System）

望闻问切是整个游戏的**统一交互语言**——不仅用于诊病，任何对象都可以用四诊来获取信息。它是玩家认知世界的核心手段。

#### 四诊定义

| 诊法 | 获取信息类型 | 适用对象举例 |
|------|------------|------------|
| 望（观察） | 外观、色泽、形态、神态 | 病人面色/舌苔、药草外形/虫蛀、矿石纹理/光泽、灵田土色 |
| 闻（嗅听） | 气味、声音、呼吸 | 病人体味/呼吸声、药草气味浓淡、矿石敲击声、环境风声虫鸣 |
| 问（询问） | 自述信息、传闻、记载 | 病人症状自述/病史、药典对药草的记载、来客提供的线索 |
| 切（触诊/感知） | 脉象、质地、灵气属性 | 病人脉象/经络状态、药草灵气浓度/药性寒热、矿石硬度/灵气属性 |

#### 四诊等级与成功率

每种诊法独立拥有等级（1-10）。等级影响两件事：**能获取的信息层级**和**判断的准确率**。

| 等级范围 | 信息层级 | 准确率 | 表现 |
|---------|---------|-------|------|
| 1-2（入门） | 模糊印象 | 40-60% | "面色似乎有些发红""这株草闻起来……有点苦？" |
| 3-4（初窥） | 基本特征 | 60-75% | "面赤，疑似实热""此草味苦，性偏寒" |
| 5-6（小成） | 详细属性 | 75-85% | "面赤目赤，脉弦数，肝火上炎""苦寒之草，入肝经，有清热之效" |
| 7-8（大成） | 深层/隐藏信息 | 85-95% | "肝火源于气滞，非单纯实热""此草兼有微毒，久服伤脾" |
| 9-10（通玄） | 完整洞察 + 直觉 | 95-99% | "气滞血瘀源于旧伤，三年前受的""此草若配甘草，毒性尽去，药效倍增" |

#### 诊断交互流程

1. 玩家选择对象（病人/药草/物品/环境）
2. 选择一种诊法执行
3. 系统根据诊法等级 + 成功率掷骰
4. **成功**：揭示该等级对应的信息层，记入药理笔记
5. **失败**：获得错误或模糊信息（玩家不确定对不对，需要交叉验证）
6. 同一对象可以使用多种诊法交叉验证，提高综合判断的可靠性

#### 误判后果

| 场景 | 误判类型 | 后果 |
|------|---------|------|
| 诊病 | 寒热辨错 | 开出反向处方 → 病人加重，声望大降 |
| 诊病 | 虚实辨错 | 补泻反了 → 无效或轻微加重 |
| 鉴药 | 药性判错 | 入方后影响疗效或产生毒副作用 |
| 鉴药 | 品阶判错 | 高估品阶导致剂量不足，低估品阶导致药力过猛 |
| 鉴物 | 属性判错 | 错过珍贵材料，或花高价买到劣品 |

#### 经验获取

- 每次使用诊法（无论成败）都积累对应诊法的经验值
- 正确诊断获得较多经验，错误诊断获得少量经验（至少知道什么是错的）
- 特殊对象（罕见病症、高品阶药材）给予额外经验
- 奇遇获得的宝物可以永久提升某一诊法的等级上限或基础准确率

### 2.2 种植系统（Garden System）

灵田是药材的核心来源。玩家在药庐周围的灵田中种植药材，从最普通的凡草开始，逐步解锁和培育高品阶灵药。

#### 灵田结构

灵田是一个**网格系统**，初始为 3×3 的小块凡土。每个格子有以下属性：

| 属性 | 说明 | 影响 |
|------|------|------|
| 土质 | 凡土/灵土/沃灵土/仙壤 | 可种植的药材品阶上限 |
| 灵气浓度 | 0-100 | 灵草生长速度和品质 |
| 五行偏属 | 金/木/水/火/土/无 | 对应属性的药材获得生长加成，相克属性减益 |
| 湿度 | 干/适中/湿 | 不同药材有不同偏好 |

#### 药材品阶与解锁

| 阶段 | 可种植品阶 | 解锁条件 | 药材举例 |
|------|----------|---------|---------|
| 凡草期 | 凡品 | 初始 | 菊花、甘草、薄荷、金银花、陈皮、生姜 |
| 灵草初阶 | 灵品下阶 | 声望达到"山野药师" + 灵田灵气 > 20 | 黄芪、当归、白术、茯苓 |
| 灵草中阶 | 灵品中阶 | 累计治愈 50 人 + 改造灵田（布聚灵阵） | 灵芝、天麻、何首乌、雪莲 |
| 灵草高阶 | 灵品上阶 | 里程碑"杏林妙手" + 灵泉引流改造 | 九节菖蒲、紫灵芝、血参 |
| 仙草 | 仙品 | 奇遇获得种子 + 仙壤 + 特殊条件 | 九转还魂草、万年冰莲、天元灵根 |

#### 种植机制

- **播种**：选择种子放入灵田格子
- **生长**：药材按品种基础周期生长，受土质/灵气/五行/季节/相邻植物影响
- **相邻互作**：
  - 五行相生的药材相邻 → 双方生长加速、品质提升
  - 五行相克的药材相邻 → 一方生长受阻、可能枯萎
  - 同品种相邻 → 竞争灵气，产量下降
- **采收**：成熟后采收获得药材，品质受生长条件综合影响（下品/中品/上品/极品）
- **季节影响**：
  - 春：种植最佳季节，大部分药材可种
  - 夏：生长加速，但虫害概率增加
  - 秋：秋收季节，部分药材仅秋季成熟
  - 冬：室外灵田休眠，仅可在药庐内窗台种植少量耐寒品种

#### 灵田改造（里程碑解锁）

| 改造 | 效果 | 解锁条件 |
|------|------|---------|
| 扩田 | 灵田从 3×3 扩展到 4×4、5×5…… | 声望里程碑 |
| 聚灵阵 | 灵田整体灵气浓度 +20 | 奇遇获得阵图 或 累计种植里程碑 |
| 灵泉引流 | 持续提供灵气 + 自动灌溉 | 高阶声望里程碑 |
| 五行转土 | 改变指定格子的五行偏属 | 特定药材知识精通后解锁 |
| 温室 | 冬季可正常种植 | 建造里程碑 |

### 2.3 处方系统（Prescription System）

处方是游戏的核心产出环节。玩家根据诊断结果选择药材组方，方剂的疗效取决于辨证是否准确和用药是否得当。

#### 药材属性模型

每种药材具有以下属性（通过望闻问切逐步揭示）：

| 属性 | 取值 | 说明 |
|------|------|------|
| 四气 | 寒/凉/平/温/热 | 药材的寒热属性，治寒证用热药、治热证用寒药 |
| 五味 | 酸/苦/甘/辛/咸（可兼有） | 影响药效方向：辛能散、苦能泄、甘能补、酸能收、咸能软 |
| 归经 | 肝/心/脾/肺/肾（可多归） | 药效作用的目标脏腑/经络 |
| 品阶 | 凡品/灵品下/灵品中/灵品上/仙品 | 影响药效强度和适用范围 |
| 毒性 | 无毒/微毒/有毒/大毒 | 有毒药材需要佐药减毒，否则产生副作用 |
| 特殊效果 | 可选 | 部分药材有独特效果（如引经、调和诸药、解百毒等） |

#### 君臣佐使组方

每张处方由四味药组成，各有职责：

| 位置 | 职责 | 规则 |
|------|------|------|
| 君 | 针对主症的核心药物 | 必须与辨证结果的病因对应（热证用寒药、虚证用补药等） |
| 臣 | 辅助君药增强疗效 | 应与君药同方向（如清热方中，臣药也偏寒凉）或兼治次症 |
| 佐 | 减毒/兼顾/反佐 | 常用于制约君药的毒性或偏性，或处理兼症 |
| 使 | 引经/调和 | 引导药力到达特定经络，或调和诸药。甘草是最常见的使药 |

#### 疗效判定

```
辨证准确度 × 用药匹配度 × 药材品质系数 = 疗效分数

疗效分数 → 判定结果：
  90+  → 药到病除（一次治愈，可能触发额外回报）
  70-89 → 见效（症状减轻，需要复诊 1-2 次）
  50-69 → 微效（略有改善，需要调方重来）
  30-49 → 无效（白费药材）
  <30  → 反效（病情加重，声望大降）
```

- **辨证准确度**：由望闻问切获取的信息是否正确决定。如果误判寒热虚实，这个系数直接崩塌
- **用药匹配度**：君臣佐使的选择是否合理。君药不对症、佐药不减毒、归经不匹配都会降低
- **药材品质系数**：品阶和品质（下品/中品/上品/极品）的加成。凡品药材系数低但及格，仙品药材系数极高

#### 风险回报：品质选择

同一张处方，玩家可以选择用不同品质的药材：

| 选择 | 疗效系数 | 代价 | 潜在额外回报 |
|------|---------|------|------------|
| 凡品药材 | ×0.6 | 低（易获取） | 基础声望 |
| 灵品下阶 | ×0.8 | 中 | 正常声望 + 小概率病人赠礼 |
| 灵品中阶 | ×1.0 | 较高 | 较高声望 + 概率获得线索/感谢信 |
| 灵品上阶 | ×1.3 | 高（稀有药材） | 高声望 + 概率触发奇遇/获得古方残页 |
| 仙品药材 | ×1.8 | 极高（极稀有） | 极高声望 + 高概率特殊奇遇 + 对该病症的深层领悟 |

这让每次开方都是一个**主动的投资决策**：用好药意味着付出更多但有概率获得稀缺回报。

#### 药理笔记

- 玩家使用过的药材组合和结果会自动记入**药理笔记**
- 效果好的组方可标记为"验方"，下次快速调用
- 随着知识积累，笔记中药材的描述从模糊到精确
- 笔记也记录失败的组合——"此方偏热，不宜用于阴虚证"

### 2.4 来客系统（Visitor System）

来客是游戏的主要内容驱动。他们带着各种需求上门，是处方系统、望闻问切系统的核心消费场景。

#### 来客类型

| 类型 | 出现条件 | 需求特点 | 奖励倾向 |
|------|---------|---------|---------|
| 凡人村民 | 初始即有 | 常见小病（风寒感冒、腹泻、跌打损伤） | 铜钱、山货、农产品 |
| 散修 | 声望 ≥ "山野药师" | 修炼相关（灵气紊乱、走火入魔初期、丹毒） | 灵石、修炼材料、信息 |
| 宗门弟子 | 声望 ≥ "灵山药师" | 疑难杂症、代师门求药 | 高阶灵石、宗门典籍、稀有种子 |
| 宗门长老 | 声望 ≥ "杏林妙手" | 陈年暗疾、罕见灵毒 | 极品材料、古方、灵田改造资源 |
| 神秘来客 | 奇遇触发 | 不可预测（可能是考验、可能是机缘） | 特殊奖励（诊术宝物、仙草种子等） |

#### 来客不只看病

来客的需求不限于治病——望闻问切可以应用于任何事物：

| 需求类型 | 说明 | 系统交互 |
|---------|------|---------|
| 求医问药 | 带病求诊，核心玩法 | 望闻问切 → 辨证 → 开方 |
| 鉴定药材 | 带来不认识的药草请你辨别 | 望闻问切鉴药 → 告知属性 → 获得报酬 + 药理知识经验 |
| 鉴定物品 | 带来不明矿石/古物请你判断 | 望闻问切鉴物 → 判断价值 → 可选收购或告知 |
| 种植咨询 | 带来种子问你适不适合种 | 结合灵田知识给出建议 → 声望 + 可能获得种子分享 |
| 买药/买材料 | 直接购买你的药材存货 | 选择卖或不卖 → 收入 |
| 带来消息 | 讲述外面的事情（世界叙事） | 被动获得信息 → 可能触发奇遇线索 |

#### 病症设计

病症由**症状组合 + 病因**构成。同样的症状可能对应不同的病因，需要通过四诊鉴别：

```
举例：
  症状：头痛、发热、恶寒
  
  可能病因 A：风寒束表（实证、寒证）
    → 治法：辛温解表
    → 君药：麻黄/桂枝类（辛温）
    
  可能病因 B：风热犯表（实证、热证）
    → 治法：辛凉解表
    → 君药：银花/连翘类（辛凉）
    
  鉴别要点：
    望 → A：面色苍白 / B：面色微红
    切 → A：脉紧 / B：脉浮数
    问 → A：怕冷为主 / B：怕热为主
```

病症复杂度随声望等级递增：

| 阶段 | 病症特点 | 举例 |
|------|---------|------|
| 初期 | 单一病因，症状明显 | 风寒感冒、腹泻、轻微外伤 |
| 中期 | 可能有兼症，需要鉴别 | 气滞血瘀、肝火犯胃、脾虚湿盛 |
| 后期 | 复合病因、隐匿症状 | 旧伤复发+新感外邪、灵气逆行+丹毒积累 |
| 高阶 | 修士特有疑难 | 走火入魔、筋脉断裂、灵毒侵体、经脉错乱 |

#### 来客叙事

每位来客除了病症外，还携带一小段叙事。这不是独立的剧情系统，而是通过来客的只言片语拼凑出外部世界的画面：

- 村民："最近山下不太平，听说有妖兽在松林出没……"
- 散修："我是从东边云霄宗赶来的，听同门说这里有位药师……"
- 宗门弟子："师叔的旧疾又犯了，长老们束手无策才让我来试试。"

这些叙事片段不需要玩家做出回应，只是为世界增加层次感。偶尔，特定叙事会成为奇遇的触发条件。

### 2.5 奇遇系统（Event System）

奇遇是日常循环中的**惊喜节点**，打破稳定节奏，提供稀缺资源和新可能性。奇遇不由玩家主动触发，而是根据条件被动出现。

#### 触发机制

奇遇有一个每日概率检定池，受以下因素加权：

| 因素 | 影响 |
|------|------|
| 声望等级 | 等级越高，高品质奇遇概率越大 |
| 当前季节 | 不同季节有不同的奇遇池（春天多植物类，冬天多来客类） |
| 近期行为 | 连续多天种植 → 提升种植类奇遇权重；连续治愈多人 → 提升来客类奇遇权重 |
| 特定条件 | 某些奇遇需要前置条件（如：拥有特定药材、达到特定知识等级） |

#### 奇遇类型

| 类型 | 说明 | 奖励举例 |
|------|------|---------|
| 灵田异变 | 灵田中的药材发生突变/异象 | 新品种种子、土质升级、灵气涌现 |
| 山中发现 | 在药庐周边发现新事物 | 天然灵泉、野生稀有药草、矿脉露头 |
| 特殊来客 | 非常规访客登门 | 古方残页、诊术秘籍、仙草种子、灵田改造图纸 |
| 古物机缘 | 来客带来/发现古老物件 | 提升四诊上限的宝物、古代药师笔记 |
| 天象/灵潮 | 特殊天象或灵气潮汐 | 全灵田灵气暴涨一段时间、特殊药材加速成熟 |

#### 奇遇示例

**"雨夜叩门"**
- 条件：冬夜 + 声望 ≥ 山野药师
- 场景：雨夜有人叩门，是一位重伤的散修，身中罕见灵毒
- 挑战：需要在有限信息下紧急开方（四诊时间缩短，压力决策）
- 成功：散修康复后赠送一册《百毒辨微录》（切诊永久 +1 级）
- 失败：散修勉强撑过但未治愈，留下线索后离去（获得部分奖励）

**"灵田异草"**
- 条件：春季 + 灵田灵气 > 40 + 种植中阶灵草
- 场景：晨起巡田发现一株从未见过的幼苗从灵田角落冒出
- 选择：精心培育（消耗大量灵气和时间）或移植到更好的位置
- 结果：根据培育方式，长成不同的稀有品种

### 2.6 成长系统（Progression System）

成长系统是所有系统的**纵向黏合剂**，驱动玩家从新手药师逐步成为一方名医。

#### 成长维度

**四诊等级**（详见 2.1）
- 望/闻/问/切各自独立升级
- 经验来源：使用对应诊法（成功多、失败少）
- 奇遇宝物可提升等级上限

**药理知识库**

玩家对每种药材的认知有独立的精通度：

| 精通度 | 状态 | 表现 |
|-------|------|------|
| 未知 | 从未接触 | 药理笔记中无此条目 |
| 模糊 | 接触过 1-2 次 | 笔记中有潦草记录和问号："苦味，似乎偏寒？" |
| 清晰 | 多次使用/诊断成功 | 笔记中记录了主要属性：四气、五味、主要归经 |
| 精通 | 大量使用 + 高等级四诊 | 完整属性 + 配伍禁忌 + 最佳搭配提示 |

**方剂册**

记录玩家使用过的所有药方组合及其效果：
- 自动记录：每次开方的药材组合 + 病症 + 疗效结果
- 验方标记：玩家可将效果好的方子标记为"验方"，后续一键调用
- 失败记录：失败的组合也会记录，标注"此方不宜用于XX证"
- 创方成就：当玩家的自创方剂累计达到一定数量且疗效达标，触发里程碑

**声望等级**

声望是核心进度指标，影响来客质量、奇遇概率、灵田解锁等：

| 声望等级 | 所需累计声望 | 解锁内容 |
|---------|------------|---------|
| 无名药师 | 0 | 初始状态，只有凡人村民上门 |
| 山野药师 | 100 | 散修开始上门，灵草初阶解锁，灵田可扩展到 4×4 |
| 灵山药师 | 500 | 宗门弟子上门，灵草中阶解锁，聚灵阵可布置 |
| 杏林妙手 | 1500 | 宗门长老上门，灵草高阶解锁，灵泉引流可建造 |
| 悬壶圣手 | 5000 | 最高阶来客和奇遇，仙草种植条件可能达成 |

声望获取：
- 治愈病人：根据病症难度和疗效获得 +5 ~ +50 声望
- 鉴定成功：+2 ~ +10 声望
- 使用高品质药材治愈：额外声望加成
- 误诊导致加重：-10 ~ -30 声望

**里程碑**

关键进度节点，触发特殊解锁：

| 里程碑 | 条件 | 解锁 |
|-------|------|------|
| 首次治愈 | 治愈第一位病人 | 药理笔记的"验方"功能 |
| 百草初识 | 药理知识库中清晰以上药材 ≥ 10 | 种植系统"五行转土"功能 |
| 悬壶济世 | 累计治愈 100 人 | 灵田扩展到最大面积 |
| 药王弟子 | 拥有 30 个疗效 90+ 的验方 | 特殊称号 + 最高阶奇遇池开放 |
| 辨证如神 | 四诊全部达到 7 级以上 | 诊断界面增加"直觉提示"辅助 |

## 3. 游戏节奏

### 时间系统

每季 **7 天**，一年 **28 天**（春/夏/秋/冬各 7 天）。

每天分为四个时段：

| 时段 | 可做的事 |
|------|---------|
| 晨（清晨） | 巡田、浇水、采收、种植 |
| 昼（白天） | 接诊来客（主要时段）、鉴定物品 |
| 暮（傍晚） | 加工炮制药材（切片/晒干/炮炙/研磨）、整理药柜 |
| 夜（夜晚） | 翻阅药理笔记复盘、研读古籍（如果有的话）、休息恢复精力 |

玩家可以自由安排时间——可以整天种地不接客，也可以跳过种植全天接诊——但每个时段结束后自动推进。

### 季节循环

| 季节 | 种植 | 来客 | 奇遇倾向 | 氛围 |
|------|------|------|---------|------|
| 春 | 播种最佳季，大部分药材可种 | 正常频率 | 灵田异变、山中发现 | 万物复苏，细雨绵绵 |
| 夏 | 生长旺季，注意虫害 | 略多（天热易中暑生病） | 天象灵潮 | 蝉鸣热浪，药香弥漫 |
| 秋 | 收获季，秋播冬菜 | 正常频率 | 古物机缘 | 层林尽染，凉风送爽 |
| 冬 | 室外休眠，室内少量 | 略少但病症更重（风寒类多） | 特殊来客（雨夜叩门类） | 大雪封山，炉火药香 |

### 第一天体验

1. 药庐中醒来，环顾四周：一间简陋的木屋，一张药案，一个空药柜，窗外是一片荒芜的小菜地
2. 药案上有一本空白的药理笔记和几包前任留下的基础药材（甘草、菊花、薄荷）
3. 出门看看菜地 → 只有一小块凡土，可以种点什么
4. 翻出角落里的几粒菊花种子 → 种下去（教学引导）
5. 回到药庐，第一位来客敲门——一个咳嗽的村民
6. 尝试望诊 → "面色有些发红……好像是热？"（信息模糊，可能不准）
7. 尝试问诊 → 村民说："咳了两天了，嗓子疼，有点怕热"
8. 综合判断：可能是风热 → 选择金银花（辛凉）为君 + 甘草为使
9. 开方后等待 → 第二天村民来复诊："好多了！"
10. 药理笔记自动记录了这个方子和结果，获得少量声望和四诊经验

### 中期体验（第 2-3 季）

- 灵田已经扩展，能种十几种药材
- 望闻问切升到 3-4 级，诊断比较靠谱了
- 来了几个散修，病症更复杂，需要仔细辨证
- 触发了第一个奇遇——在灵田角落发现一株野生灵芝
- 药柜里存货丰富，可以做出品质选择了：给这个散修用好药搏一搏？

### 后期体验（第 2 年+）

- 灵田布满聚灵阵，能种植高阶灵药
- 四诊等级 7-8，基本一眼看出问题所在
- 宗门长老上门求诊，考验你对复杂病症的理解
- 药理笔记密密麻麻记满了验方和知识
- 偶尔有神秘来客带来意想不到的机缘
- 享受一个药师大成后的山间日常

## 5. 美术风格

### 风格定位

**水墨国风像素（Ink-wash Pixel Art）**，清雅自然色调。

追求修仙世界的"仙气"与山间药庐的"烟火气"共存。不是浓墨重彩的华丽修仙，而是淡墨留白的隐居山人。

### 色板

- 主色调：水墨灰、宣纸黄、竹青绿
- 药材色系：草绿、枯黄、丹红、玄紫、雪白
- 灵气色系：淡蓝、翠碧（灵气流动效果用）
- 点缀色：朱砂红（UI 强调）、金色（成就/里程碑）

- 水墨风独立游戏的像素化表达
- 修仙小说插图的意境感
- 中药铺/药柜的视觉元素

### 场景清单

| 场景 | 说明 | 交互内容 |
|------|------|---------|
