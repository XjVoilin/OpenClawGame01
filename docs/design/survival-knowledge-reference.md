# Off Trail — 荒野生存知识参考手册

> 每个技能点包含：真实原理、关键细节、游戏化转译、反馈设计、野外笔记文本。

## 一、火与热

### 1.1 摩擦生火（弓钻法）

**真实原理**

弓钻法（Bow Drill）是最可靠的原始摩擦生火方法，尤其适合寒冷潮湿气候。原理是用弓带动木轴高速旋转，木轴底端与火板摩擦产生高温木屑粉末（约400°C），积累在火板的V形缺口中形成炭火种（ember），再转移到引火巢中吹燃。

**关键细节**
- **木材选择**：轴和火板应使用软木到中软木——雪松、柳木、白杨、椴木效果最好。硬木（橡木、白蜡木）摩擦产热太慢
- **弓**：手臂长度的弯曲树枝，系上坚韧绳索（筋腱、皮条或植物纤维绳）
- **手持块**：硬木或石头，中间有浅凹槽。需要润滑（树脂、油脂）以减少顶部摩擦
- **火板**：平底板，刻一个浅坑放置木轴，旁边刻V形缺口让火粉掉落
- **引火巢**：干燥的细碎纤维（干草、桦树皮细丝、松针、干苔藓）捏成鸟巢状
- **常见失败原因**：木材含水（需要死立木而非地面的）、绳索太松打滑、V形缺口太小火粉散不出来、引火巢不够蓬松

**游戏化转译**
- 站点：地面/手持
- 输入：木棍 + 绳索 + 干燥木板 → 制作弓钻套件
- 使用弓钻套件 + 干草 → 生火操作（小游戏或等待时间）
- 简化方案：燧石 + 干草 也可以直接打火（更简单但需要燧石）

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 成功 | 冒烟 → 火星 → 火苗动画，噼啪音效 |
| 接近成功 | 冒出淡烟但熄灭（木材太湿/引火物不够干） |
| 失败 | 木棍转动但无烟（完全不搭配的木材） |

**野外笔记文本**
- 模糊记录：「试着转动木棍让它冒烟了，但火怎么都起不来……是木头的问题？还是那团草不够干？」（配手绘弓钻草图，木轴部分画了问号）
- 完整记录：「弓钻生火法——用雪松或柳木做轴和板最好。板上要刻V形口让火粉落下来。引火巢要用最干最细的草丝。手持块上抹点树脂能省力。」（配完整弓钻结构图，标注各部件名称）
- 进阶提示：「桦树皮丝是最好的引火物，一点火星就能燃起来。」

### 1.2 火堆维护与火种类型

**真实原理**

不同的柴火堆叠方式产生不同效果。锥形堆（Teepee）引火快但燃烧快；井字堆（Log Cabin）持久稳定；达科他火坑（Dakota Fire Hole）是挖两个相连地洞，隐蔽且抗风，进气孔提供自然鼓风效果，热效率极高。

**关键细节**
- **燃料三级**：引火物（干草、桦树皮、松针）→ 细枝（铅笔粗细）→ 粗柴（手臂粗）。必须按顺序逐级添加
- **木材差异**：针叶木（松、杉）燃烧快、火焰大但不持久，适合引火；阔叶硬木（桦、橡）燃烧慢但热量高、炭火持久，适合维持
- **火种保存**：用干腐木（punk wood）或真菌火绒（如马蹄菌）可以长时间保持阴燃状态携带火种
- **雨天生火**：死立木内部通常是干燥的；桦树皮含油脂，即使潮湿也能燃烧
- **常见失败原因**：柴火堆叠太密不透气、直接用粗柴引火、雨天用地面湿木

**游戏化转译**
- 火堆是一个持续交互站点，有燃烧状态（未点燃/微火/中火/旺火/余烬）
- 玩家需要持续添柴维持火焰——不同燃料影响火焰强度和持续时间
- 针叶木柴：快速升温但消耗快；硬木柴：缓慢但持久
- 火堆强度影响制作能力（微火只能取暖，中火能烹饪，旺火能烧陶）

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 添加合适柴火 | 火焰增大动画，噼啪声加强 |
| 柴火太大（粗柴直接压） | 火焰被压小、冒浓烟 |
| 添加湿木 | 大量白烟，滋滋声，火焰减弱 |
| 火快灭了 | 火焰变小变暗，偶尔闪烁 |

**野外笔记文本**
- 模糊记录：「火总是烧着烧着就灭了。是不是柴加得不对？」（配火堆图，旁边画了几根粗细不同的木棍打了叉和勾）
- 完整记录：「先用干草和细枝点燃，等细枝烧旺了再慢慢加粗柴。松木烧得快但不耐久，桦木和橡木火力足还耐烧。」（配火堆截面图，标注三层燃料结构）
- 进阶提示：「挖两个相连的地洞生火，风会自动从一个洞灌进来，火特别旺还不怕风吹灭。」

### 1.3 烟熏保存

**真实原理**

烟熏通过两种机制保存食物：一是热量蒸发食物中的水分（微生物无法在缺水环境生长）；二是烟中含有的酚类化合物和醛类物质抑制霉菌和酵母的生长。冷熏（低于30°C）需要数天到数周，保存期最长；热熏（55-80°C）同时烹熟和保存，数小时即可完成。

**关键细节**
- **木材选择**：硬木（橡木、桦木、枫木）产生的烟最好。避免针叶木（松、杉），其树脂产生的烟有苦味且可能有害
- **肉的处理**：切成不超过6mm厚的薄片，挂在距火堆上方的架子上
- **烟熏架**：用三脚架或四根木桩搭建，横放几根木棍作为搁架，高度约60-90cm
- **时间**：热熏约4-8小时，肉变硬变暗即可；冷熏需要密封空间维持低温烟雾数天
- **保存效果**：烟熏肉/鱼可保存数周到数月
- **湿木产烟**：需要用湿木或绿木覆盖炭火来产生浓烟而非明火

**游戏化转译**
- 站点：烟熏架（需要先建造）
- 输入：生肉/生鱼 + 持续的烟（火堆上方放置烟熏架 + 添加湿木产烟）
- 需要维持数个游戏小时
- 产出：熏肉/熏鱼（保质期大幅延长）

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 正常烟熏中 | 持续烟雾缭绕，肉色逐渐变深 |
| 火太旺（明火而非烟） | 肉变焦/烤糊了，变成烤肉而非熏肉 |
| 烟不够（火灭了） | 烟消散，肉没有变化 |
| 完成 | 肉色完全变深，质地变硬，闪光提示 |

**野外笔记文本**
- 模糊记录：「把肉放在烟上面好像能让它不那么快坏掉……但直接烤糊了好几次。」
- 完整记录：「烟熏法——搭个架子把薄肉片挂在烟上方。不要明火！用湿木头盖在炭火上才能出浓烟。硬木的烟最好，松木的烟有苦味。熏上半天肉就变硬变深色了，能存好久。」
- 进阶提示：「鱼比肉更适合烟熏。切得越薄，熏得越快越均匀。」

### 1.4 木炭烧制

**真实原理**

木炭是木材在缺氧环境下高温热解（约400-500°C）的产物。木材中的水分和挥发性成分被驱除，留下几乎纯碳的结构。木炭比木材的热值高约两倍，且燃烧温度更高（可达1100°C以上），这是冶炼金属所必需的。

**关键细节**
- **土窑法（Earth Mound/Clamp）**：最古老的方法。将木材码成圆锥形堆，中间竖三根木桩作为烟囱，外面覆盖枯叶/草再糊上湿泥土密封。从顶部点火，通过底部的通风孔控制进气量
- **坑烧法（Earth Pit）**：挖一个深坑，填满木材点燃，等充分燃烧后用泥土覆盖隔绝空气。更简单但质量不稳定
- **判断进度的关键**：观察烟的颜色——浓白烟表示水分在蒸发；薄蓝烟表示正在碳化；烟几乎消失或变清透表示过度燃烧，需立即封死
- **时间**：小型土窑约12-24小时；大型需要数天
- **产出率**：约5份木材产1份木炭（按重量）

**游戏化转译**
- 站点：土窑（需要建造：木材 + 泥土）
- 输入：大量木材，点燃后需要用泥土封顶
- 需要等待较长游戏时间（过夜）
- 玩家可以观察烟色判断进度，在正确时机完全封死通风口

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 正在碳化 | 烟从白色逐渐变蓝，窑体微微发红 |
| 过度燃烧 | 烟变清透/消失，窑内出现明火光芒 → 木材烧成灰了 |
| 正确时机封死 | 烟停止，等待冷却后获得木炭 |
| 密封不严 | 侧面漏烟，部分木材变成灰 |

**野外笔记文本**
- 模糊记录：「把木头埋在土里烧……结果有的变成黑炭，有的直接烧成灰了。怎么才能全都变成炭？」
- 完整记录：「土窑烧炭法——把木材竖着码成堆，中间留个烟囱通道。外面先盖草再糊泥密封。从顶上点火后盯着烟的颜色：白烟→蓝烟→快没烟的时候赶紧把所有通风口封死。等上一天再开窑。」
- 进阶提示：「硬木烧出的炭比软木好——更重、更耐烧、温度更高。这种炭才能用来炼铁。」

### 1.5 锻造炉与冶炼

**真实原理**

原始炼铁使用的是"块炼炉"（Bloomery），是一种直径25-50cm、高约1m的圆柱形黏土炉。将铁矿石和木炭交替分层装入炉中，通过底部的风嘴（tuyère）用风箱持续鼓风。木炭燃烧产生的一氧化碳在高温下与铁矿石中的氧化铁反应，还原出金属铁。产物是一块混合了�ite（铁渣）的海绵状铁块（bloom），需要反复加热锤打去除渣质才能变成可用的熟铁。

**关键细节**
- **铁矿来源**：沼铁矿（bog iron）是最易获取的原始铁矿，它是溪流/沼泽边被细菌沉积的含铁沉淀物，呈红褐色。溪谷边的红色泥巴/砂砾很可能就含有可用铁矿
- **矿石预处理**：焙烧（roasting）——先在普通火堆中烧烤矿石去除水分和部分杂质
- **炉子建造**：黏土混合沙子和草（防止开裂），筑成圆柱形。底部留风嘴孔，前方可留出渣口
- **温度要求**：需要达到约1200°C以上，只有木炭+持续鼓风才能达到（普通木柴火堆最高约700°C）
- **鼓风**：皮囊风箱或用空心管吹气
- **时间**：一次冶炼约6-10小时
- **产出**：30-40kg矿石约产出3-20kg铁块（bloom），还需锤炼加工
- **常见失败原因**：温度不够（风量不足）、矿石含铁量太低、炉壁开裂

**游戏化转译**
- 站点：锻造炉（需要建造：石头 + 黏土 + 建造技巧）
- 前置：需要木炭（普通木柴温度不够）和风箱（皮革 + 木框）
- 输入：含铁泥土/沼铁矿 + 木炭，玩家需要操作风箱维持温度
- 产出：铁块（bloom），还需要在砧石上锤打加工成铁器

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 温度达标 | 炉口发出橙红光芒，持续的低沉轰鸣声 |
| 温度不够 | 炉口暗红/无光，矿石变黑但不融化（接近成功） |
| 冶炼成功 | 从炉底取出发红的铁块，锤打时火星四溅 |
| 使用木柴而非木炭 | 火焰旺但炉口不够红，矿石无变化（提示需要更高温燃料） |

**野外笔记文本**
- 模糊记录：「溪谷那边有种红褐色的泥巴，放进火堆里烧完以后变得很硬，里面好像有什么亮闪闪的东西……」
- 完整记录：「炼铁——溪谷东侧的红泥就是铁矿！先在火堆里焙烧去湿，然后放进黏土砌的炉子里和木炭一层层交替铺好。关键是要用风箱不停鼓风——只有木炭加足够的风才能热到把铁炼出来。炼出来的铁块还得趁热锤打去渣。」
- 进阶提示：「炉壁用黏土混沙子和草筑成，不容易裂。风嘴要从底部斜着插进去，风才能吹到木炭上。」

## 二、水与食

### 2.1 溪水与饮水安全

**真实原理**

野外溪水即使看起来清澈，也可能含有贾第鞭毛虫（Giardia）、隐孢子虫（Cryptosporidium）、大肠杆菌等病原体。这些微生物来自上游的动物排泄物。症状包括腹泻、呕吐、发烧，在生存环境下可能致命，因为会导致严重脱水。

**关键细节**
- **相对安全的水源**：流动的溪水比静水安全；泉眼处的水（刚从地下涌出）最安全；雨水收集也相对干净
- **危险水源**：静止的池塘、沼泽水、动物活动频繁区域的下游
- **应急饮水**：极度缺水时喝溪水比不喝强，但要做好可能生病的准备

**游戏化转译**
- 溪水可以直接饮用，但有概率导致"不适"状态（移速减慢、体力恢复降低）
- 不适概率根据水源类型不同：泉眼5%，流动溪水20%，静水池50%
- 这个概率是隐藏的，玩家通过经验积累才能发现规律

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 正常饮水 | 口渴度恢复，无异常 |
| 饮水后不适 | 角色捂肚子动画，状态栏出现"不适"图标 |
| 泉眼饮水 | 口渴度恢复更多，几乎不会不适 |

**野外笔记文本**
- 模糊记录：「喝了溪水之后肚子不舒服了……是不是水有问题？」
- 完整记录：「溪水不能直接放心喝。流动的水比死水安全，从地下冒出来的泉水最好。最保险的办法是把水烧开再喝。」
- 进阶提示：「用木炭碎、沙子和草分层铺在容器里，水倒进去过滤一遍再烧开，就更干净了。」

### 2.2 净水（煮沸与木炭过滤）

**真实原理**

煮沸是最可靠的野外净水方式——持续沸腾1分钟即可杀死绝大多数病原体（高海拔地区需3分钟）。木炭过滤器利用木炭的多孔结构吸附水中的有机物、部分化学物质和异味，但不能杀菌，所以过滤后仍需煮沸。

**关键细节**
- **煮沸**：需要耐火容器（陶碗/陶罐）和火。石头烧热后放入盛水的非耐火容器（树皮碗、木碗）中也能加热水——称为"石煮法"
- **木炭过滤器**：从下到上分层——草/布 → 小石子 → 沙子 → 碎木炭。水从顶部倒入，从底部流出
- **木炭制备**：必须用天然木柴烧成的木炭（不是灰），碾碎使用
- **过滤器局限**：木炭会饱和失效，需要定期更换；不能去除所有化学污染；不能杀菌
- **容器**：可用中空的竹子、掏空的木头、桦树皮卷成锥形

**游戏化转译**
- 方法一：容器 + 水 → 放在火上煮沸 → 净水（最简单）
- 方法二：建造过滤器（木炭 + 沙子 + 石子 + 容器）→ 生水倒入 → 过滤水 → 再煮沸 → 高质量净水
- 净水消除饮水不适的概率
- 石煮法：石头放入火堆加热 → 热石头放入盛水树皮碗 → 水沸腾

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 水煮沸 | 容器中冒泡沸腾动画 |
| 过滤中 | 水缓慢滴下，从浑浊变清澈 |
| 石煮法 | 石头放入水中滋滋冒泡，水开始翻滚 |
| 用陶碗直接烧水 | 正常加热 |
| 用树皮碗直接上火 | 容器烧毁（提示需要石煮法或换容器） |

**野外笔记文本**
- 模糊记录：「把水烧开了再喝好像就不会肚子疼了……但树皮碗放火上直接烧破了。」
- 完整记录：「净水法——最简单的是把水装进陶碗放火上烧开。没有陶碗的话，可以把石头在火里烧红了放进盛水的树皮碗里，水也能烧开。更讲究的做法是先用碎木炭和沙子过滤一遍再烧开。」
- 进阶提示：「用石头烧水要选河边圆滑的石头，不要选有层理的片状石头——那种受热会炸裂。」

### 2.3 植物辨识

**真实原理**

北方针叶林中有大量可食用和有用植物，但也有致命的有毒植物。现实中的"万用测试法"（Universal Edibility Test）是一套系统的试吃流程，但在游戏中可以简化。

**关键细节**
- **可食用植物举例**（北方针叶林适用）：
  - 蓝莓/越橘：灌木丛中，夏末秋初成熟，安全美味
  - 蒲公英：整株可食用，叶子做沙拉，根可烘烤做饮品
  - 松针：可泡茶，富含维生素C（预防坏血病关键）
  - 桦树汁：早春时节划开桦树皮即可采集，微甜，可直接饮用
  - 牛蒡根：秋冬挖取，煮食
  - 野生蘑菇中的安全种类：鸡油菌（金黄色喇叭状）、牛肝菌
- **有毒植物举例**：
  - 毒蝇伞（红底白点蘑菇）：经典毒蘑菇
  - 毒芹/水毒芹：看起来像胡萝卜但极度致命
  - 白色浆果：经验法则——白色浆果几乎都有毒
- **辨识线索**：苦涩味、乳白色汁液、三片小叶的组合、白色或黄色浆果——这些通常是危险信号

**游戏化转译**
- 未知植物首次拾取时显示为"未知浆果"、"未知蘑菇"等
- 食用后根据实际效果记录到野外笔记：安全/有毒/药用
- 多次接触同类植物后逐渐能在拾取时就辨认
- 某些植物有季节性——只在特定季节出现/可采集

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 食用安全植物 | 正常进食动画，饱食度恢复 |
| 食用有毒植物 | 角色不适动画，生命值持续下降，可能呕吐 |
| 食用药用植物 | 特殊状态恢复（如松针茶恢复少量生命） |
| 辨认出已知植物 | 植物名称和安全性图标直接显示 |

**野外笔记文本**
- 模糊记录：「吃了一种红色的小果子，味道还不错。但另一种白色的让我吐了……」（配简笔画浆果图，红色打勾，白色打叉）
- 完整记录：「安全果实——蓝色小圆果（蓝莓）在灌木丛中到处都是，夏末最多。红色小圆果也能吃。但白色浆果千万别碰！蘑菇里金黄色喇叭状的能吃，红色带白点的绝对有毒。」
- 进阶提示：「松针可以泡水喝，味道有点酸但喝了感觉好多了。早春的桦树划一刀能流出甜水。」

### 2.4 陷阱制作

**真实原理**

原始猎捕陷阱利用机械原理自动捕获猎物，效率远高于主动追猎。核心是在动物的必经之路上设置触发机关。套索陷阱（Snare）利用弹性树枝或重物的能量，当动物触碰触发棍时，套索收紧。压落式陷阱（Deadfall）利用重物下落击杀猎物。

**关键细节**
- **套索陷阱（Snare）**：
  - 核心部件：绳套、弹性杆（弯曲的活树枝）、触发棍
  - 绳套直径约为目标动物头部的1.5倍
  - 设置在动物跑道上（寻找脚印、粪便、啃食痕迹确认跑道）
  - 兔子跑道通常在灌木丛底部的狭窄通道
- **压落式陷阱（Deadfall）**：
  - "四"字形触发结构：三根木棍组成"4"字形支撑结构，顶着一块重石/重木
  - 动物碰到诱饵棍 → 支撑崩塌 → 重物落下
  - 重物应为猎物体重的5-10倍
- **设置要点**：多设几个陷阱提高概率；放置在有动物活动痕迹的地方；每天检查
- **适合捕获的猎物**：兔子、松鼠、旱獭等小型动物

**游戏化转译**
- 站点：地面放置
- 套索陷阱：绳索 + 木棍 → 在动物跑道附近放置
- 压落式陷阱：绳索 + 木棍 + 重石 → 在动物跑道附近放置
- 陷阱是被动的——放置后每天有概率捕获猎物，概率受放置位置影响
- 在有动物脚印/粪便的位置放置成功率高

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 放置在好位置 | 可以看到附近有脚印/粪便 |
| 捕获猎物 | 回来检查时发现陷阱触发，猎物在里面 |
| 空陷阱 | 陷阱完好但无猎物 |
| 陷阱损坏 | 被大型动物踩坏或风吹倒 |

**野外笔记文本**
- 模糊记录：「用绳子做了个圈套放在树林里，但一直没逮到东西……是不是放的位置不对？」
- 完整记录：「套索陷阱——找到兔子的跑道（地上有小脚印和粪粒的窄道），把绳圈挂在跑道上方一拳高的位置。弯一根有弹性的活树枝连着绳套，兔子碰到就会被弹起来吊住。多放几个提高成功率。」
- 进阶提示：「压落式陷阱用三根棍搭成'四'字形撑住一块大石头，下面放诱饵。动物碰诱饵棍就被砸住。石头要够重——至少是猎物体重的五倍。」

### 2.5 钓鱼

**真实原理**

原始钓鱼不限于钓竿——还有鱼叉、鱼笼、石堰等方式。骨钩是最古老的鱼钩形式之一。鱼叉适合在浅水和清澈溪流中对付可见的鱼。鱼笼/鱼篓是编织的漏斗状陷阱，鱼游进去就出不来。

**关键细节**
- **骨钩钓鱼**：
  - 用动物骨头磨制成钩形，或者用硬木削制"卡喉钩"（gorge hook，一根两头尖的小棍，鱼吞下后横在喉咙里）
  - 鱼线：植物纤维绳索或动物筋腱
  - 鱼竿：长直的柳枝或其他有弹性的枝条
  - 鱼饵：虫子、浆果、小块肉
- **鱼叉**：长直木杆，前端分叉并削尖，用在浅水清流中
- **鱼笼**：用柳条编织漏斗形入口，鱼能进不能出，放在溪流中
- **石堰**：在溪流浅处用石头摆成V形，尖端指向下游，鱼被引导集中到出口处容易捕捉

**游戏化转译**
- 骨钩钓鱼：骨钩 + 植物纤维线 + 木杆 → 在溪边使用（小游戏或等待）
- 鱼叉：尖木棍，在浅水区直接使用（需要准确操作）
- 鱼笼：柳条编织，放在溪流中被动捕鱼（类似陷阱）
- 石堰：在浅滩用石头搭建，引导鱼群便于捕捉

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 钓到鱼 | 鱼线绷紧动画，拉上来的鱼挣扎 |
| 鱼叉命中 | 水花溅起，鱼被钉住 |
| 鱼笼有收获 | 回来检查时篓内有鱼在游动 |
| 无收获 | 等了很久，鱼线没动静 / 鱼笼空着 |

**野外笔记文本**
- 模糊记录：「在溪边等了半天啥也没钓到。是不是没用对诱饵？或者应该换个地方试试？」
- 完整记录：「钓鱼——用骨头磨个弯钩，系上植物纤维的线，绑在柳枝竿上。虫子做饵最好用。溪流拐弯处的深潭鱼最多。还可以用柳条编一个漏斗形的鱼笼放在水里，鱼进去就出不来。」
- 进阶提示：「在浅滩用石头摆成V字形，尖端朝下游，鱼会自动被引到最窄处，用鱼叉很容易扎到。清晨和傍晚鱼最活跃。」

### 2.6 简单种植

**真实原理**

原始农业的核心是观察哪些植物自然生长在哪里、收集种子或可移栽的植物部位、创造有利生长条件。北方针叶林的生长季节短（约3-4个月），限制了可种植的作物种类。

**关键细节**
- **适合的作物**：根茎类（萝卜、芜菁）生长快耐寒；叶菜类（野生菠菜替代品）；葱蒜类野生品种
- **土壤改良**：溪边的淤泥肥沃；草木灰是天然肥料（含钾和钙）；腐叶堆肥
- **种植流程**：翻土松土（用尖棍或石锄）→ 播种或移栽 → 浇水 → 等待
- **种子来源**：从野生可食植物上采集成熟种子/果实
- **时间窗口**：春季融雪后到秋季霜冻前
- **主要挑战**：动物来吃（需要围栏）、霜冻、干旱

**游戏化转译**
- 玩家需要先获得种子（从野生植物采集）
- 选择合适位置（溪边沃土更好）翻土 → 播种 → 定期浇水
- 作物有生长周期（数天）
- 春夏种植，秋冬无法种植
- 可以用篱笆防止动物破坏

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 播种成功 | 土地上出现小苗标记 |
| 作物生长中 | 随时间可见植物变大 |
| 缺水 | 植物颜色变黄发蔫 |
| 被动物吃了 | 植物消失，地面有脚印 |
| 收获 | 成熟的果实/根茎可采摘 |

**野外笔记文本**
- 模糊记录：「把吃剩的浆果种子埋进土里……不知道能不能长出来。」
- 完整记录：「种植——从野生植物上收集成熟的种子。选溪边肥沃的黑土，用尖棍翻松。春天播种最好。要记得浇水，草木灰撒一些能帮助生长。秋天霜冻前一定要收获完。」
- 进阶提示：「用木桩和树枝围一圈篱笆，不然兔子会把嫩苗全吃光。溪边的淤泥混进土里能让地更肥。」

## 三、居所

### 3.1 树下避雨

**真实原理**

大型针叶树（如云杉）的树冠层层叠叠，天然形成雨伞效果，树干附近的地面往往是干燥的。这是最快的临时庇护方案，但保温效果有限。

**关键细节**
- **最佳选择**：大型云杉/冷杉，低矮的枝条形成天然围挡
- **增强方法**：在树根旁堆积落叶和松针做垫层隔绝地面寒气（地面散热是体温流失的主要途径）
- **注意**：雷雨天不要躲在孤立大树下（雷击风险）；避免枯死的树（断枝风险）

**游戏化转译**
- 在大树旁可以"休息"，提供最低限度的遮蔽
- 减缓体温下降速度，但不能完全阻止
- 如果收集落叶铺在地上，保温效果提升

**野外笔记文本**
- 模糊记录：「大云杉树底下比外面暖和一点，至少不直接淋雨。但地面冰凉冰凉的……」
- 完整记录：「临时避雨——找大云杉，树冠能挡大部分雨。在树根旁堆厚厚的落叶和松针当垫子，不要直接躺在地上，地面会把体温全吸走。」

---

### 3.2 碎屑棚（Debris Hut）

**真实原理**

碎屑棚是最高保温效率的原始庇护所，原理类似全身睡袋。核心是一根倾斜的脊梁杆，两侧覆盖树枝框架，最外面厚厚地堆上落叶、松针等碎屑做保温层。内部空间故意做得很小——刚够一个人躺进去——这样体温能快速暖热空气。

**关键细节**
- **脊梁杆**：约3m长，直径8cm以上，一端架在树桩或Y形树杈上（高约腰部），另一端放地面
- **框架**：两侧斜插较粗的树枝（肋骨状），上面铺一层细枝条
- **保温层**：至少60cm厚的干燥碎屑（落叶、松针、干蕨类）——越厚越暖。用一些细枝压住防止被风吹走
- **内部铺垫**：地面也要铺厚厚的碎屑
- **建造时间**：2-4小时
- **入口**：可以用背包或一捆树枝堵住
- **温度效果**：即使外界零下，内部靠体温就能维持在0°C以上

**游戏化转译**
- 手工建造（不需要站点）：大量树枝 + 大量落叶/松针
- 建造耗时较长（消耗体力）
- 提供良好的保温和遮蔽，但空间极小（只能睡觉，不能做别的）
- 可以修缮和增厚保温层

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 建造中 | 逐步可见框架搭建、碎屑覆盖的动画 |
| 保温层足够 | 进入后体温下降极慢 |
| 保温层不够 | 进入后仍然缓慢降温（提示需要更多碎屑） |
| 雨天 | 碎屑棚能防小雨，暴雨会渗透 |

**野外笔记文本**
- 模糊记录：「用树枝搭了个棚子，但晚上还是冷得够呛。是不是叶子盖得不够厚？」
- 完整记录：「碎屑棚——找一根长粗木杆斜靠在树桩上做屋脊。两边插满树枝做骨架，再铺一层细枝。最外面堆上厚厚的落叶和松针——至少要比手臂还厚才行！里面空间要小，刚够钻进去躺下，这样体温才能把小空间暖起来。地面也要铺干叶子。」
- 进阶提示：「入口可以用一捆草堵住。干蕨叶的保温效果比普通落叶好。」

---

### 3.3 斜靠棚（Lean-To）

**真实原理**

斜靠棚是最简单的开放式庇护所——一面斜墙，通常配合前方的火堆使用。火堆的热量被斜面反射回来形成温暖的空间。缺点是只能挡一个方向的风雨。

**关键细节**
- **搭建**：一根横杆架在两棵树之间或两个Y形支架上，斜靠大量树枝做成倾斜的墙面
- **覆盖**：最外层铺上大片树皮、松枝或树叶防水
- **配合火堆**：在开口面1-2m处生一长条火堆，热量会被斜面反射
- **反射墙**：在火堆的另一侧再立一面斜墙，可以进一步反射热量
- **优点**：建造简单快速，开放面可以靠火堆取暖
- **缺点**：保温不如碎屑棚，风向改变时会吹进来

**游戏化转译**
- 手工建造：树枝 + 树叶/树皮
- 建造速度快（比碎屑棚省时间和体力）
- 配合前方火堆使用时保温效果不错
- 单面遮蔽——风向影响效果

**野外笔记文本**
- 模糊记录：「靠着树搭了一面斜墙挡风，前面烤火，背后还是冷。」
- 完整记录：「斜靠棚——两棵树之间架横杆，斜插一排树枝做墙面，外面铺上松枝和树皮防水。面朝开口生一堆长火堆，热气会被斜面弹回来。」
- 进阶提示：「在火堆另一侧也立一面矮墙反射热量，两面夹着烤，比单面暖得多。」

---

### 3.4 原木框架与完整木屋

**真实原理**

原木木屋（Log Cabin）是最经典的长期荒野居所。核心结构是将原木水平叠摞，在交叉角处刻制凹槽（notch）使其互锁。缝隙用苔藓、泥巴或草填塞（chinking）以防风保温。

**关键细节**
- **地基**：选择排水良好的平地，用大石头或粗原木做地基隔离地面湿气
- **墙体**：原木去皮（防虫防腐），两端刻凹槽交叉叠摞。每层之间夹苔藓做密封层
- **凹槽类型**：最简单的是"鞍形槽"——在原木上方刻半圆形凹槽让上层原木卡进去
- **屋顶**：脊梁+檩条+劈开的半圆木瓦或桦树皮铺面防水
- **门窗**：墙体搭好后用石斧锯开门洞，上方需要加横梁承重
- **工具需求**：最低需要石斧；有铁斧会大大提高效率
- **缝隙填塞**：苔藓+泥巴的混合物塞入原木之间的缝隙
- **时间**：一人独力建造一间小木屋可能需要数周

**游戏化转译**
- 分阶段建造：
  1. 木屋框架：原木 + 绳索 → 搭建基本框架（需要工作台/石斧）
  2. 完整木屋：框架 + 木板 + 苔藓/泥巴 → 封墙和屋顶
- 每个阶段消耗大量材料和体力
- 完成后提供最佳保温和遮蔽，可以内部放置工作台、储物等

**野外笔记文本**
- 模糊记录：「想盖个真正的房子……但光是把原木搬过来就累得够呛，而且叠起来总是歪。」
- 完整记录：「木屋搭建——先在平地上用石头垫出地基。原木去皮，两端刻凹槽让它们交叉咬合。每层之间塞苔藓防风。屋顶用斜放的半圆原木或桦树皮盖住防水。缝隙全用苔藓混泥巴堵严实。」
- 进阶提示：「木板比圆木更平整好叠，但需要用斧头劈——有铁斧能快好几倍。门洞上方一定要加粗横梁，不然上面的原木会压塌。」

### 3.5 壁炉

**真实原理**

石砌壁炉的核心是烟囱效应——热空气上升从烟囱排出，同时把烟一起带走，保持室内空气清新。壁炉同时提供取暖和室内烹饪功能。

**关键细节**
- **选材**：河卵石或平整石块，用黏土混合物做黏合剂
- **结构**：火箱（放柴火的地方）+ 烟道（从火箱上方收窄连接到烟囱）+ 烟囱（穿过屋顶通向外面）
- **关键尺寸**：烟囱内径不小于火箱开口面积的1/10，否则排烟不畅
- **石头选择**：避免河里的圆石和有层理的石头——受热可能炸裂。选择干燥的、质地均匀的石头
- **黏合剂**：黏土 + 沙子 + 干草混合，需要高温"烧结"后才会牢固
- **安全**：壁炉背面和两侧不能紧贴木墙，需要留气隙或用石头/黏土做隔热层

**游戏化转译**
- 站点建造：大量石头 + 黏土 → 在木屋内建造
- 建造完成后，木屋内可以生火且烟会自动排出
- 提供室内取暖 + 烹饪双重功能
- 建造不当会导致排烟不畅（室内冒烟）

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 正常使用 | 壁炉火光映照室内，烟从烟囱排出 |
| 排烟不畅 | 室内弥漫烟雾，角色咳嗽 |
| 石头炸裂 | 用了不合适的石头，受热后"砰"一声裂开 |

**野外笔记文本**
- 模糊记录：「在屋里生火差点被烟呛死，烟全倒灌进来了……得想办法让烟往上走。」
- 完整记录：「壁炉——用平整石头和黏土砌成，上面接烟囱通到屋顶外。烟囱要够宽烟才排得出去。石头不要用河里捡的圆卵石，受热会炸。黏土里掺沙子和干草才结实。」
- 进阶提示：「壁炉后背和两侧别贴着木墙，留点空隙或者垫一层石板隔热，不然时间久了木头会被烤着。」

## 四、工具

### 4.1 石器打制

**真实原理**

燧石打制（Flint Knapping）是人类最古老的技术之一。利用富含硅质的石头（燧石、黑曜石、碧玉、石英岩）受力时会产生贝壳状断裂（conchoidal fracture）的特性，通过有控制的敲击来塑造锋利的刃口。

**关键细节**
- **适合的石材**：燧石（flint）、黑曜石、碧玉（jasper）、石英岩——细粒硅质岩石，断裂面光滑锋利。敲击时发出高音清脆声的石头通常适合打制
- **两种技术**：
  - 打击剥片（Percussion Flaking）：用硬的锤石敲击母岩，剥下大片石片。用于粗加工
  - 压力剥片（Pressure Flaking）：用骨尖或鹿角尖顶住石片边缘施压，剥下细小薄片。用于精修刃口
- **石斧制作**：将打制好的石刃用绳索/皮条/植物纤维绑在劈开的木柄上，缝隙中塞入树脂胶加固
- **石刀**：大型锋利石片本身就可以直接作为刀使用
- **注意**：打制过程会产生极其锋利的碎片

**游戏化转译**
- 站点：地面/手持
- 石斧：合适的石头 + 木棍（+ 绳索/树脂胶增强绑定）
- 石刀：合适的石头敲击出锋利石片
- 不是所有石头都适合——只有特定的石头（燧石等）能打制工具
- 石器有耐久度，使用一段时间后会钝化/破碎

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 成功打制 | 清脆的"叮"声，石片剥落 |
| 石头不适合 | 沉闷的"咚"声，石头碎裂但无锋利边缘 |
| 绑柄成功 | 石刃和木柄结合的动画 |

**野外笔记文本**
- 模糊记录：「敲了好多石头，大部分碎成渣了。但有一种灰色的石头敲出来的片特别锋利……」
- 完整记录：「石器——找灰色或黑色的细密石头（敲起来声音清脆的那种），用另一块硬石头瞄准边缘敲，能削下锋利的石片当刀用。要做石斧，把石片劈进木棍的缝里用绳子绑紧。」
- 进阶提示：「用骨头或鹿角的尖端去顶石片边缘，能更精细地修整刃口。抹上桦树皮胶能把石刃固定得更牢。」

---

### 4.2 骨器加工

**真实原理**

骨头经过适当加工可以制成针、钩、锥、刮刀等精细工具。骨头比石头更容易加工成细长形状，非常适合做鱼钩和缝针。

**关键细节**
- **材料来源**：猎物的腿骨（最坚硬）、肋骨、鹿角
- **加工方式**：用石刀刻出大致形状 → 在粗糙石头上磨制成型 → 在细砂石上打磨光滑
- **骨针**：取薄骨片，磨成细长形，一端磨尖，另一端用石锥钻一个针眼
- **骨钩**：取骨片磨成弯钩形，尖端磨锐
- **骨锥**：骨头尖端磨锐，用于在皮革上扎孔
- **鹿角工具**：鹿角的分叉可以做锄头或耙子，尖端可做压力剥片工具

**游戏化转译**
- 站点：地面/手持（用磨石加工）
- 动物骨头 + 磨石 → 骨针/骨钩/骨锥
- 鹿角 → 鹿角锄/鹿角工具
- 需要先有猎物（陷阱或钓鱼获得）

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 磨制中 | 沙沙的摩擦声，骨头逐渐成型 |
| 骨头断裂 | 咔嚓声，骨头从中间断开（用力方向不对） |
| 成功 | 光滑的成品，微微反光 |

**野外笔记文本**
- 模糊记录：「吃完兔子剩的骨头，形状倒是有点像能用的东西……能不能磨一磨？」
- 完整记录：「骨器——动物腿骨最硬最好用。用石刀先刻出大概形状，再在粗石头上反复磨。做鱼钩就磨成弯的，做针就磨细磨尖再钻个小孔。鹿角的叉可以当锄头用。」
- 进阶提示：「骨针配上动物筋搓成的线，就能缝皮革做衣服了。」

### 4.3 绳索编织（反向缠绕法）

**真实原理**

反向缠绕法（Reverse Wrap）是最基本也最可靠的原始绳索制作方法。两束纤维各自向一个方向扭紧（顺时针），然后两束互相向反方向缠绕（逆时针），产生的扭力让绳索自锁，不会散开。

**关键细节**
- **纤维来源**：
  - 树皮内层（桦树皮、椴木皮、雪松皮）——需要浸泡后撕成细条
  - 荨麻茎——晒干后捶打，剥出外皮纤维，是强度最高的植物纤维之一
  - 动物筋腱（sinew）——最强韧的天然绳索材料
  - 酢浆草、蕨类根部等
- **采集时机**：树皮在春季树液流动时最容易剥取
- **浸泡（沤麻）**：将树皮/植物茎在水中浸泡3-7天，软化后更容易分离纤维
- **接长**：一束纤维快用完时，将新纤维搭在旧纤维末端一起缠绕进去（错开两束的接头位置以保持强度）
- **速度**：熟练后每小时可以搓4-5m绳

**游戏化转译**
- 站点：手工制作
- 植物纤维/树皮 → 绳索
- 不同材料做出的绳索强度不同（树皮绳 < 纤维绳 < 筋腱绳）
- 绳索是许多物品的关键中间材料（弓、陷阱、绑缚工具、建造）

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 编织中 | 双手搓绳的动画 |
| 纤维太短 | 绳索散开（需要更长的纤维或正确的接续方式） |
| 成功 | 一段结实的绳索 |

**野外笔记文本**
- 模糊记录：「试着把树皮撕成条搓在一起，但搓出来的东西一拉就断了……」
- 完整记录：「绳索——把树皮泡几天水再撕成细条。取两束纤维，每束各自拧紧，然后两束反方向互相缠绕。一束快用完时搭上新纤维继续缠，错开接头就不会断。桦树皮和荨麻茎的纤维最好用。」
- 进阶提示：「动物的筋腱晒干后搓成的绳最结实，做弓弦最好。春天树液流动时树皮最容易剥。」

### 4.4 木工

**真实原理**

原始木工依赖石斧或铁斧进行伐木、劈柴、削制。将圆木劈成木板是一项关键技能——使用楔子（石制或木制）沿木纹方向打入圆木，利用木材的天然纹理进行劈裂。

**关键细节**
- **伐木**：石斧效率低（砍倒一棵中等树可能需要数小时），铁斧效率高数倍
- **劈木板**：在圆木端面找到天然裂纹，用石楔/木楔沿纤维方向逐步劈开。不是"锯"出来的，是沿纹理"劈"出来的
- **削制**：用石刀或铁刀削平表面、制作木钉、雕刻凹槽
- **木材选择**：直纹理的软木（松、杉）最容易劈板；弯曲或有结的木材很难劈
- **干燥**：新鲜砍的湿木（green wood）容易加工但会收缩变形；干燥的木头更稳定但更硬

**游戏化转译**
- 站点：工作台
- 原木 + 石斧/铁斧 → 木板/木桩
- 铁斧比石斧效率高很多（时间更短、体力消耗更少）
- 木板是建造木屋和家具的核心材料

**野外笔记文本**
- 模糊记录：「想把圆木弄成平板，但用石斧乱砍一通只弄出一堆碎木渣……」
- 完整记录：「劈木板——找纹理直的松木或杉木，在端面找到天然裂缝。削一个木楔子或石楔打进去，沿纹理方向一点一点劈开。不要横着砍，要顺着木纹劈。」
- 进阶提示：「铁斧做的楔子比石头的好用太多了，劈板子快了好几倍。新砍的湿木比干木容易劈，但劈好了要放一阵子让它干透才不会变形。」

### 4.5 铁器锻造

**真实原理**

从块炼炉中取出的铁块（bloom）是海绵状的粗铁，混合了大量�ite。必须反复在高温下加热到红热状态，然后用石锤在砧石上锤打，挤出渣质并使铁颗粒结合成致密的金属块。之后可以将铁块锤打拉长、折叠、塑形为工具。

**关键细节**
- **砧石**：一块大而平整的硬石头，或一截粗硬木桩
- **锤**：最初用石锤，后来可以先做一把铁锤
- **加热**：需要持续在锻造炉中用木炭+鼓风加热到红热（约800-1000°C），铁在此温度下变软可以锤打
- **锻造流程**：加热→取出→锤打（几十秒内必须完成，冷了就锤不动）→放回加热→重复
- **工具成型**：刀——锤打拉长成条状，一侧磨薄做刃；斧——锤打成扁平状，中间弯折包住木柄
- **淬火**：成型后烧到红热快速放入水中冷却——增加硬度（但也增加脆性）

**游戏化转译**
- 站点：锻造炉 + 砧石
- 铁块 + 高温炉 → 取出红热铁块 → 在砧石上锤打
- 反复加热和锤打的过程（小游戏或简化的多次操作）
- 可以锻造：铁刀、铁斧、铁钩等
- 铁器耐久度远高于石器

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 锤打正确 | 叮叮当当的金属声，火星四溅，铁块逐渐成型 |
| 铁冷了还锤 | 沉闷的声音，铁不变形（提示需要重新加热） |
| 淬火 | 滋滋冒烟声，水面翻腾 |
| 成品 | 闪亮的铁器，反射光芒 |

**野外笔记文本**
- 模糊记录：「从炉子里掏出来的铁疙瘩又软又脆，怎么把它变成工具？」
- 完整记录：「铁器锻造——把炼出来的铁块在锻造炉里用木炭烧到通红发软，趁热取出在大平石上锤打。要反复加热-锤打好多遍，每次铁里的渣都会被挤出来一些，铁变得越来越密实。锤成想要的形状后，烧红了丢进水里——能让它更硬。」
- 进阶提示：「先做一把铁锤——有了铁锤之后锻造其他东西就容易多了。折叠锤打（反复加热折叠锤平）能让铁更加均匀结实。」

## 五、容器

### 5.1 桦树皮容器

**真实原理**

桦树皮天然防水、柔韧、耐用，是北方森林中最理想的天然容器材料。桦树皮含有桦木脂（betulin），使其天然防水防腐。可以折叠成碗、盒、甚至独木舟。

**关键细节**
- **采集时机**：春季树液流动期（4-6月）最容易剥取大片完整的树皮
- **采集方法**：在活树上环切一圈，纵切一刀，用木片沿形成层轻轻撬起。只取外层树皮，不伤内层，树不会死
- **容器制作**：将树皮裁成展开图形状，折叠成容器，边缘用细根（云杉根）或绳索缝合
- **防水性**：桦树皮本身防水，但缝合处需要用树脂胶密封
- **耐热**：桦树皮容器装满水后可以放在火上——水温不超过100°C，树皮不会燃烧（类似纸锅煮水的原理）。但空容器不能放在火上
- **其他用途**：桦树皮丝是极好的引火物（含油脂，潮湿也能烧）

**游戏化转译**
- 站点：手工制作
- 桦树皮 + 云杉根/绳索 → 桦树皮碗/桦树皮盒
- 可以盛水、储物
- 装满水后可以在火上加热（石煮法的替代方案）

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 制作成功 | 折叠缝合的动画 |
| 空容器上火 | 容器烧毁 |
| 装水容器上火 | 水开始冒泡，容器完好 |

**野外笔记文本**
- 模糊记录：「桦树皮撕下来能折成碗的样子，但装水会漏。怎么才能不漏？」
- 完整记录：「桦树皮碗——春天的时候桦树皮最好剥。沿着树干切一圈再竖切一刀，用木片慢慢撬。折成碗的形状后用细根缝合边缘，缝口涂上松脂胶防漏。装满水以后甚至可以放在火上烧开水——但空碗千万别放火上。」
- 进阶提示：「桦树皮的细丝是最好的引火物，就算潮湿的也能点着——因为里面含油。」

### 5.2 烧制陶器（坑烧法）

**真实原理**

陶器是人类最早的化学材料工艺之一。黏土在约700°C以上发生不可逆的化学变化（脱水+烧结），从软泥变成坚硬的陶。原始烧陶不需要窑——直接在火坑中烧（pit firing）即可。

**关键细节**
- **黏土采集**：溪边、河岸、沼泽地的黏性泥土。好的黏土捏起来光滑不散，干了不裂（或少裂）
- **黏土处理**：去除石子杂质；加入砂子或碾碎的旧陶片（熟料/chamotte）防止干燥和烧制时开裂
- **成型**：泥条盘筑法——把黏土搓成长条，一圈圈盘上去筑成碗/罐的形状，再用手抹平内外表面
- **干燥**：成型后必须完全晾干（至少数天），含水的陶在烧制时会炸裂——这是最常见的失败原因
- **坑烧法**：先用硬木烧出一堆炭火 → 在炭火上放石头隔离 → 将干透的陶器放上去 → 先在旁边预热（逐渐靠近火堆）→ 最后堆上柴火覆盖焚烧 → 让它自然冷却
- **温度**：约780-830°C，硬木效果最好
- **成功率**：原始坑烧成功率约60-80%，主要看干燥是否彻底和升温是否均匀

**游戏化转译**
- 步骤一：在溪谷采集黏土 → 揉捏成型（手工）
- 步骤二：晾干（需要等待游戏时间）
- 步骤三：放入火堆中烧制（需要旺火）
- 有概率失败（没干透会炸裂）

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 烧制成功 | 陶器颜色从灰变红/橙，质地变硬 |
| 含水炸裂 | "砰"的一声，碎片飞溅（没干透） |
| 火力不够 | 陶器颜色变深但不够硬，拿出来后容易碎 |
| 冷却太快 | 出现裂纹（自然冷却才行） |

**野外笔记文本**
- 模糊记录：「把泥巴捏成碗放火里烧，结果砰一声炸了……是不是哪里没做对？」
- 完整记录：「烧陶——溪边的黏土最好，捏之前要混一些细砂进去。搓成长条一圈一圈盘成碗的形状，抹平。捏好后一定要晾好几天直到完全干透！然后先在火堆旁慢慢烤热，最后埋进旺火里烧。烧完让它在灰里自然凉透再拿。」
- 进阶提示：「壁厚要均匀，2-5mm最好，太厚容易炸。加了碎陶片或砂的泥不容易裂。棱角要做圆润，尖角容易开裂。」

---

### 5.3 编织篮筐

**真实原理**

编织是利用柔韧材料的交叉结构创造容器的技术。底部通常用辐射状排列的硬骨架（经），侧面用柔软的编条（纬）交替穿过骨架缠绕而上。

**关键细节**
- **材料**：
  - 柳条——最经典的编筐材料，柔韧度极佳
  - 桦树细枝
  - 云杉根——浸泡后非常柔韧
  - 藤蔓
- **处理**：采集后需要浸泡使其柔软（干燥的柳条会折断）
- **基本编法**：底部用8-10根较粗的骨架呈米字形排开，然后用细条在骨架间穿入穿出逐圈编上去
- **收口**：顶部将骨架弯折编回，形成牢固的边缘
- **用途**：采集篮、储物筐、鱼笼

**游戏化转译**
- 站点：手工制作
- 柳条/藤蔓 → 浸泡 → 编织 → 篮筐
- 篮筐用于增加采集携带量
- 鱼笼用柳条编织，放在溪流中被动捕鱼

**野外笔记文本**
- 模糊记录：「想用柳条编个筐，但干柳条一弯就断了。」
- 完整记录：「编筐——柳条和藤蔓都行，但一定要先泡水泡软。底部用粗的排成米字形骨架，然后用细条在骨架间穿来穿去一圈一圈往上编。收口把骨架弯折编回去就牢了。」
- 进阶提示：「同样的方法编成漏斗状就是鱼笼——鱼能进不能出。云杉根泡过水以后特别柔韧好编。」

---

### 5.4 木桶

**真实原理**

木桶制作（制桶术/Coopering）是较为高级的木工技术。桶壁由多块弧形木板（桶板/stave）拼合，用箍（绳索或铁圈）紧箍。在原始条件下可以用掏空木头的方式做简易木桶。

**关键细节**
- **简易方法**：找一段粗木头（直径30cm+），用石斧/铁斧和火的配合掏空内部——先在中间烧一个凹坑，再用工具刮除炭化的部分，反复交替
- **桶板法**：将直纹理木头劈成弧形板，削薄修整，排列成圆筒用绳索或柳条箍紧
- **密封**：缝隙用苔藓/树脂填塞。木头吸水膨胀后也会自动密封缝隙
- **用途**：储水、储粮、腌制食物

**游戏化转译**
- 站点：工作台
- 简易方法：粗木段 + 火 + 石斧/铁斧 → 掏空木桶
- 桶板法：木板 + 绳索 → 木桶（需要较高的木工技巧）

**野外笔记文本**
- 模糊记录：「想做个大容器装水……用原木掏空？但好难啊，石斧效率太低。」
- 完整记录：「木桶——最简单的办法是找段粗木头，在中间点火烧出凹坑，再用斧子挖掉焦炭部分。反复烧和挖就能掏出一个大容器。讲究点的做法是劈出弧形木板拼成桶再用绳箍紧。」
- 进阶提示：「木桶装水放一两天，木头膨胀了缝隙就会自动封住。用来腌渍食物保存效果很好。」

## 六、皮革与保暖（新增类别）

### 6.1 脑鞣法制皮

**真实原理**

脑鞣法（Brain Tanning）是将生皮变成柔软耐用皮革的最古老方法。动物脑中的乳化脂肪酸和卵磷脂能渗透进皮革胶原纤维，在每根纤维表面形成防水涂层，阻止纤维粘连（粘连的纤维 = 硬邦邦的生皮），从而使皮革保持柔软。巧合的是，每只动物的脑正好够鞣它自己的皮。

**关键细节**
- **流程**：
  1. 剥皮：从猎物身上完整剥下
  2. 刮脂：去除皮下所有残肉和脂肪
  3. 脱毛：浸泡数天使毛囊松动，然后刮去毛发和外层表皮
  4. 制脑液：将动物脑煮成乳白色液体
  5. 浸泡：将皮浸入脑液2-8小时
  6. 拉伸晾干：这是最关键的步骤——在皮革干燥过程中必须持续拉伸、揉搓、抻扯，持续2-8小时。如果不拉伸，纤维会粘在一起变成硬皮
  7. 烟熏：在硬木的阴燃烟雾上方熏20-30分钟/面——赋予防水性和防腐性
- **替代材料**：如果没有脑，可用6-12个蛋黄、煮熟的骨髓、或动物脂肪+肝脏代替
- **时间**：完整处理一张皮需要数天
- **产物**：柔软的鹿皮（buckskin），可用于制作衣物、袋子、绳索

**游戏化转译**
- 多步骤制作过程：
  1. 生皮 → 在水中浸泡 → 用石刀/骨刮刀刮毛去脂
  2. 脑 + 水 + 火 → 脑液
  3. 刮好的皮 + 脑液 → 浸泡 → 拉伸晾干
  4. 晾干的皮 + 烟 → 烟熏皮革（成品）
- 每步之间需要等待时间
- 是制作保暖衣物的前置技能

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 刮制中 | 刮刀在皮面上来回的动画 |
| 浸泡脑液 | 皮变色变软 |
| 拉伸中 | 皮逐渐变白变柔软 |
| 忘记拉伸 | 皮干了但是硬邦邦的（变成生皮而不是皮革） |
| 烟熏完成 | 皮色变为暖棕色，柔软有质感 |

**野外笔记文本**
- 模糊记录：「把猎物的皮晾干了，硬得像块木板，这能穿吗……」
- 完整记录：「鞣皮——剥皮后先刮干净所有残肉和脂肪，泡水几天后刮掉毛。把动物脑煮成乳白色汁液，将皮泡进去几个小时。最关键的是泡完之后要一直拉啊揉啊抻啊直到干透——不拉就会变成硬皮！最后在阴燃的硬木烟上面熏一遍就防水了。」
- 进阶提示：「每只动物的脑正好够鞣它自己的皮。没有脑的话蛋黄也行。烟熏用的木头要用硬木，不要松木。」

---

### 6.2 毛皮处理与保暖衣物

**真实原理**

在极寒环境中，皮毛衣物是最有效的保暖方案。与鞣皮不同，处理毛皮时要保留毛发。处理方式更简单——主要是刮除皮下脂肪和残肉，然后干燥或用盐/脑液处理防腐。

**关键细节**
- **简易处理**：刮脂 → 绷紧在框架上晾干 → 用脑液/脂肪涂抹皮面软化
- **缝合**：骨针 + 动物筋腱搓成的线（sinew thread）——筋腱干燥后收紧，缝合非常牢固
- **衣物设计**：
  - 毛皮外套：多张皮拼缝
  - 手套/帽子：较小的皮（如兔皮）
  - 靴子：厚实的鹿皮底部+毛皮上部
- **保暖原理**：毛发之间的空气层是最好的隔热层

**游戏化转译**
- 处理后的毛皮 + 骨针 + 筋线 → 毛皮衣物
- 毛皮衣物大幅提升保温能力（冬季核心装备）
- 不同动物的毛皮保暖效果不同

**野外笔记文本**
- 模糊记录：「冬天太冷了，是不是可以把猎物的毛皮穿在身上？但直接披着又臭又硬。」
- 完整记录：「毛皮——和鞣皮不同，这次要保留毛。刮掉皮下面的肉和油，绑在木框上撑平晾干。皮面涂上脑液或油脂搓软。然后用骨针和筋线缝成衣服。毛朝里穿最暖。」

---

### 6.3 简易缝合（骨针与筋线）

**真实原理**

骨针是人类最早的精密工具之一（距今约4万年）。配合动物筋腱搓成的线，可以缝合皮革、制作衣物和袋子。

**关键细节**
- **骨针制作**：取薄骨片磨成细长形（3-8cm），一端磨尖，另一端用小石锥旋转钻孔做针眼
- **筋线**：取动物腿部的长筋腱，晾干后可以撕成细丝。干筋腱在穿过针眼后遇到皮革中的水分会膨胀，使缝合点更加紧密
- **缝合前**：用骨锥在皮革上预先扎孔，再穿针引线
- **用途**：缝合衣物、修补帐篷/庇护所、制作皮水袋

**游戏化转译**
- 骨针 + 筋线 是缝合操作的工具前提
- 用于将皮革/毛皮缝制成衣物、袋子、鞋等
- 也可以用来修补庇护所

**野外笔记文本**
- 模糊记录：「有了皮革，但怎么把几块拼起来做成能穿的东西？需要针和线……」
- 完整记录：「骨针缝合——把骨头磨成细针，用石锥在一端钻个小眼儿。线用动物腿上的筋腱晾干后撕成细丝。缝皮革之前先用骨锥扎好孔再穿针。筋线遇潮会膨胀把缝口撑得更紧。」

---

## 七、天然粘合（新增类别）

### 7.1 桦树皮焦油

**真实原理**

桦树皮焦油（Birch Bark Tar）是人类已知最古老的胶水，至少有19万年历史，尼安德特人就在使用。通过干馏（在缺氧条件下加热）桦树皮来提取。

**关键细节**
- **最简单方法——露天凝结法**：
  在河卵石旁边燃烧桦树皮，焦油蒸汽会凝结在冷的石头表面上，用工具刮下来收集。约1小时即可获得少量可用焦油。产量小但简单快速
- **坑烧法**：
  将桦树皮卷紧放入密封的坑/容器中加热（隔绝空气），焦油会从底部流出。产量更大但需要5小时以上
- **性质**：黑色粘稠物质，冷却后变硬变脆。加热后变软可以塑形和粘合。可以反复加热使用
- **用途**：粘合石器与木柄（比单纯绑缚牢固得多）、密封桦树皮容器的缝隙、防水处理

**游戏化转译**
- 站点：火堆
- 桦树皮 + 石头 + 火 → 少量桦树皮胶
- 用途广泛：加固工具绑定、密封容器、粘合修补

**反馈设计**
| 情况 | 反馈 |
|------|------|
| 正在制作 | 桦树皮在火中冒出浓黑烟，石头表面出现黑色液珠 |
| 成功 | 刮下黑色粘稠物质 |
| 温度太高 | 焦油全部燃烧蒸发，石头表面什么都没有 |

**野外笔记文本**
- 模糊记录：「烧桦树皮的时候旁边的石头上沾了些黑乎乎粘粘的东西……这是什么？」
- 完整记录：「桦树皮胶——在石头旁边烧桦树皮，黑色的焦油会凝结在冷的石头表面。刮下来就是天然胶水。加热变软，冷了变硬。可以用来把石斧头粘在木柄上、堵容器的缝。」
- 进阶提示：「把桦树皮卷紧塞进泥封的小坑里烧，底下放个容器接，能一次收集更多焦油。但要注意别让空气进去，不然皮会直接烧掉而不是出焦油。」

### 7.2 松脂胶

**真实原理**

松树受伤时会流出树脂（resin）封住伤口。收集的松脂可以加热融化后混合碳粉（木炭粉）制成强力胶水——松脂胶（pine pitch glue）。

**关键细节**
- **采集**：找松树/云杉树干上的天然树脂渗出点，用石片刮下。已经凝固变白的也可以用
- **制作**：
  1. 将松脂在容器中用小火缓慢融化（不要用大火，会燃烧）
  2. 加入约1/3体积的碾碎木炭粉——增加硬度和耐热性
  3. 还可以加入少量动物粪便/植物纤维增加韧性
  4. 搅拌均匀后趁热涂抹使用，或者倒在木棍末端凝固保存（使用时再加热）
- **性质**：比桦树皮焦油容易获得但强度略低。耐水性好
- **用途**：密封容器、粘合工具、防水处理、火把制作（松脂是极好的助燃物）

**游戏化转译**
- 站点：火堆
- 松脂 + 木炭粉 + 微火加热 → 松脂胶
- 比桦树皮焦油更容易获得（松树很常见），但略弱
- 松脂本身也是好的引火助燃物

**野外笔记文本**
- 模糊记录：「松树上那些粘乎乎的黄色东西好像能粘住些东西。」
- 完整记录：「松脂胶——刮下松树上渗出的树脂，用小火慢慢融化（别用大火会烧着）。加进碾碎的木炭粉搅匀，冷了就变成很硬的胶。要用的时候再烤软。可以粘工具、封容器的缝。」
- 进阶提示：「把松脂胶糊在木棍顶端再裹上桦树皮丝就是简易火把。纯松脂也是很好的引火物——一点就着。」

---

## 八、狩猎与防御（新增类别）

### 8.1 简易弓

**真实原理**

自制弓是荒野中最有效的远程工具。弓的原理是利用弓身木材的弹性储存能量，通过弦释放给箭矢。

**关键细节**
- **弓材**：最好的是榆木、白蜡木、紫杉。在北方针叶林中，桦木是最佳选择，其次是落叶松
- **制作**：
  - 选一根直且无结的细树干（约1.5m长，底部直径5cm左右）
  - 将新鲜的绿木晾干数天（完全干透的太脆，新鲜的太软）
  - 削制弓身：横截面呈D形——平面朝外（弓背），圆面朝内（弓腹）
  - 两端削出弦槽
  - 逐渐弯曲试拉，确保两臂弯曲均匀
- **弓弦**：最好用动物筋腱搓成的绳（最强韧），或植物纤维绳
- **箭**：直且细的树枝（60-75cm长），尾端劈开夹入羽毛（fletching），前端装石制或骨制箭头用松脂胶和绳索固定

**游戏化转译**
- 弓：合适的木材 + 刀/斧（削制）+ 弦（筋腱绳/纤维绳）
- 箭：直木枝 + 羽毛 + 石/骨箭头 + 胶
- 弓用于远程狩猎（大型猎物如鹿）和防御
- 需要一定操作技巧（瞄准）

**野外笔记文本**
- 模糊记录：「砍了根树枝弯一弯想做弓，结果一拉就断了。」
- 完整记录：「制弓——选没有节疤的直桦木杆，不要太干也不要太湿。削成里面圆外面平的形状。弓弦最好用动物筋搓的绳。箭用直细木枝削光，尾端夹羽毛让它飞得稳，前端绑上石头磨的尖头。」
- 进阶提示：「弓两臂的弯曲要一样均匀，不然射不准还容易断。弓不用的时候把弦解开，让弓身休息。」

---

### 8.2 矛与投矛器

**真实原理**

矛是最原始也最实用的武器/工具。投矛器（Atlatl）是利用杠杆原理延长手臂有效长度的投掷辅助工具，可以将矛掷出更远、更快、更有力。

**关键细节**
- **简单矛**：长直木杆（2m+），前端削尖，在火上烤硬（加热使木材表面碳化硬化）
- **石尖矛**：在矛头绑上石制尖头——劈开矛杆前端夹入石片，用绳索和树脂胶固定
- **投矛器**：约60cm长的木板/木棍，一端有钩或凹槽卡住矛的末端。投掷时投矛器充当手臂的延伸，显著增加投掷速度和距离
- **用途**：钓大鱼、防御野兽、远程投掷猎杀

**游戏化转译**
- 简单矛：长木棍 + 火堆烤硬前端
- 石尖矛：矛杆 + 石头尖 + 绳索/胶
- 投矛器：木板/木棍 + 削制
- 矛用于防御（赶走野兽）和在浅水叉鱼

**野外笔记文本**
- 模糊记录：「削尖了根长木棍，但刺东西的时候尖儿总是折断或者弯了。」
- 完整记录：「矛——选直硬的木杆，前端削尖后放在火上慢慢烤到颜色变深——烤过的尖头硬很多。更好的是在前端绑上石头磨的尖。劈开矛头，夹进石尖，用绳子绑紧再涂上胶。」
- 进阶提示：「做一块有凹槽的木板当投矛器，投的时候把矛尾卡在凹槽里用力一甩——比徒手扔远多了也有力多了。」

## 九、草药与急救（新增类别）

### 9.1 止血与伤口处理

**真实原理**

野外伤口处理的核心是：止血 → 清洁 → 防感染。许多植物含有收敛（收缩组织）和抗菌成分，可以辅助处理。

**关键细节**
- **止血**：
  - 直接压迫是最有效的止血方式（用干净的布/苔藓压住）
  - 蓍草（Yarrow）：北方常见，白色伞状花序。捣碎的叶子敷在伤口上有强力止血效果——这也是它的拉丁名 Achillea（阿喀琉斯之草）的由来
  - 泥炭藓（Sphagnum Moss）：沼泽中大量生长，天然抗菌且吸水性极强，历史上广泛用作伤口敷料
- **伤口清洁**：用清洁水（最好是烧开过的）冲洗
- **防感染**：松脂有天然抗菌性，可以薄涂在伤口上
- **蜂蜜**：如果能找到野蜂巢，蜂蜜是极佳的天然抗菌敷料

**游戏化转译**
- 受伤状态：劳动/意外导致"伤口"状态 → 持续缓慢掉血
- 基础处理：苔藓/干净布料 → 压迫止血（停止掉血但不治愈）
- 草药处理：蓍草叶 → 捣碎敷伤口（加速愈合）
- 高级处理：烧开水清洗 + 蓍草 + 松脂涂抹（完全治疗）

**野外笔记文本**
- 模糊记录：「砍柴的时候割到手了，流了好多血。用苔藓按住好像止住了，但伤口还是疼。」
- 完整记录：「伤口处理——先用苔藓或干净的东西压住止血。沼泽里的软苔藓（泥炭藓）最好，不容易感染。白色小伞花的草（蓍草）捣碎敷上去愈合更快。先用烧开过的水洗干净伤口再敷药更安全。」
- 进阶提示：「松脂薄薄涂一层在伤口上也能防感染。如果找到了蜂窝，蜂蜜是最好的天然伤口药。」

### 9.2 常用药用植物

**真实原理**

北方针叶林中有多种具有药用价值的植物。在没有现代药物的情况下，这些植物的价值不可估量。

**关键细节**
- **松针茶**：松针富含维生素C（是柑橘的5倍），泡水喝可预防坏血病。在漫长冬季没有新鲜蔬果时至关重要
- **蓍草**：止血、消炎、退烧。泡茶喝可缓解感冒症状
- **桦树皮**：含水杨苷（阿司匹林的天然前体），泡茶有止痛退烧功效
- **泥炭藓**：天然抗菌敷料
- **蒲公英**：利尿、助消化。根煮水可做代咖啡饮品
- **松脂**：外用抗菌

**游戏化转译**
- 松针 + 热水 → 松针茶（恢复少量生命、预防"坏血症"状态）
- 蓍草 → 捣碎敷伤口（止血消炎）/ 泡茶（缓解生病状态）
- 桦树皮 → 泡茶（止痛退烧）
- 冬季如果长期不摄入维生素C → "坏血症"debuff → 松针茶是解药

**野外笔记文本**
- 模糊记录：「泡了一碗松针水喝，味道酸酸的，但好像精神了一点？」
- 完整记录：「药用植物——松针泡水能防坏血病，冬天一定要喝。白色小伞花的蓍草能止血退烧。桦树内皮泡水能止疼。沼泽的软苔藓可以当绷带。」
- 进阶提示：「冬天存一些干蓍草和桦树皮，生病受伤的时候用得着。松脂涂在伤口上能防感染，虽然有点疼。」
