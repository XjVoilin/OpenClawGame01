# 退休小院 —— 游戏设计文档

## 1. 概述

**类型**：治愈向等距视角庭院建造经营游戏

**核心体验**：从一片荒地开始，自由建设属于自己的退休小院。种菜、养花、养动物、建房子、制作食物，享受悠闲的乡村退休生活。

**背景设定**：轻量叙事——城里人退休回老家，爷爷留下一块荒地。开头简短交代，之后不再有剧情推进。

**目标平台**：PC (Steam) 优先，后续考虑移植移动端

**参考方向**：Stardew Valley 的经营节奏 + 动物森友会的自由度 + 等距视角的空间表现力

---

## 2. 核心设计决策

| 维度 | 决策 |
|------|------|
| 视角 | 等距 (Isometric) 伪3D |
| 建造方式 | 网格式 |
| 核心驱动 | 里程碑/成就引导，不强制 |
| 时间系统 | 昼夜 + 四季循环（行为消耗 + 缓慢流逝） |
| 院子扩展 | 逐步解锁扩建 |
| 制作系统 | 轻量多步骤（需建设施，最多3层） |
| 动物系统 | 有产出功能，需喂食但轻负担 |
| 经济系统 | 来客订单模式 |
| 角色状态 | 软限制（时间流逝，天黑自然收工） |
| 叙事 | 轻量背景 |
| 美术策略 | 先用占位/成套资源，系统与美术解耦 |

---

## 3. 系统设计

### 3.1 地图网格系统 (World Grid)

**基础结构**：
- 等距菱形格子，每格是最小放置单位
- 初始区域约 12×12 格，扩建每次增加约 6×8 格
- 格子状态：未开荒（杂草/石头/树桩）→ 已清理（空地）→ 已占用

**地块类型**：
| 类型 | 说明 |
|------|------|
| 空地 | 可放置任何东西 |
| 土地 | 已翻土，可种植作物 |
| 水域 | 固定位置小池塘，养鱼用 |
| 硬地 | 已铺路/铺砖，放置建筑和设施 |

**开荒机制**：
- 清除障碍物消耗游戏内时间，不同障碍物耗时不同（杂草 < 石头 < 树桩）
- 清除后获得基础材料（石头、木材、杂草纤维）

**深度排序**：
- Y 坐标越小越先渲染
- 高物体通过 sorting order 动态计算
- 不使用 Unity 自带 Isometric Tilemap，自行管理格子数据 + Sprite 渲染

---

### 3.2 时间与季节系统 (Time)

**一天结构**：
```
清晨(6:00) → 上午(8:00) → 中午(12:00) → 下午(14:00) → 傍晚(18:00) → 夜晚(21:00)
```

**时间驱动方式（行为消耗 + 缓慢流逝）**：
- 基础流速：挂机不操作约 30 分钟真实时间 = 1 游戏天
- 行为加速：种一格菜 +15分钟，建造 +30~60分钟，制作按配方定
- 提供 1x / 2x / 3x 加速按钮

**天黑效果（软限制）**：
- 傍晚：光线变暖变暗（URP 2D Light 渐变）
- 夜晚：视野缩小为角色周围光圈
- 不禁止操作，视觉引导休息
- 点击回屋 → 结算当天 → 进入第二天

**一天结算**：
- 作物生长推进
- 动物产出刷新
- 制作进度推进
- 来客刷新
- 自动存档

**季节**：
| 季节 | 天数 | 特色 |
|------|------|------|
| 春 | 15 天 | 大部分蔬菜适种，花卉发芽 |
| 夏 | 15 天 | 高温作物快，部分花盛开 |
| 秋 | 15 天 | 果实成熟，桂花开放，丰收季 |
| 冬 | 10 天 | 可种作物少，适合建造/整理/囤货 |

- 一年 = 55天 ≈ 27小时游戏时长（基础流速不加速）
- 换季前有视觉提示，非当季作物换季后枯萎

---

### 3.3 种植系统 (Farming)

**作物生命周期**：
```
播种 → 发芽 → 成长(多阶段) → 成熟 → 收获
                                    ↓ (超时未收)
                                  枯萎
```

**核心规则**：
- 种在土地格子上，播种前需翻土
- 每种作物有适宜季节，非当季无法种植
- 生长按游戏天数推进（快的3天，慢的7-10天）
- 每天浇一次加速生长，不浇不死但速度减半
- 成熟后有3-5天收获窗口，超期枯萎

**作物分类**：
| 类别 | 示例 | 用途 |
|------|------|------|
| 蔬菜 | 白菜、萝卜、辣椒 | 制作食物、完成订单 |
| 谷物 | 糯米、小麦 | 制作糕点基础材料 |
| 花卉 | 菊花、茉莉 | 装饰、制作花茶 |

**树木**：
- 占 2×2 格，长期生长（跨多个季节）
- 成熟后每季开花/结果一次
- 不需要浇水，种下后自行生长
- 产出通过手动采摘收集

**围栏与花卉**：
- 围栏沿格子边缘放置（不占格子内部空间）
- 围栏旁可种低矮花卉，按季节自动开放/凋谢
- 花卉不需特别照料，纯观赏 + 少量采集

---

### 3.4 建造系统 (Building)

**核心操作只有两个：建造、拆除**

**建造**：选择物件 → 放置模式（绿色可放/红色不可放）→ 确认 → 消耗材料+时间 → 完成

**拆除**：移除建筑 → 返还 50%-70% 材料 → 格子恢复空地 → 瞬间完成

**升级方式**：拆旧建新。想要更好的设施就拆掉旧的，建造高级版本。统一逻辑，无论占地是否变化都通过拆除+重建处理。

**建筑分类**：
| 类别 | 示例 | 功能 |
|------|------|------|
| 住宅 | 主屋（可多级重建） | 休息/存档点 |
| 生产设施 | 灶台、晾晒架、石磨、腌制缸 | 制作加工前置 |
| 养殖设施 | 鸡舍、鸭棚、鱼塘 | 动物居所 |
| 功能设施 | 仓库、水井、饲料槽、堆肥箱 | 辅助功能 |
| 装饰 | 石灯、木椅、花架、小路 | 纯美观 |

**建造约束**：
- 每建筑有固定占地（1×1、2×2、2×3等）
- 必须在已清理格子上
- 部分设施有前置条件（灶台需先有主屋）

**进阶路径示例**：
| 设施 | 等级路径 | 变化 |
|------|----------|------|
| 主屋 | 茅草屋 → 土砖房 → 青瓦院 | 变大变好看，解锁室内功能 |
| 灶台 | 野外篝火 → 土灶 → 砖灶 → 大厨房 | 可用配方增多，速度提升 |
| 晾晒架 | 简易竹架 → 木制晒架 → 带棚晒场 | 容量增加，雨天不受影响 |
| 鸡舍 | 露天围栏 → 小木棚 → 正经鸡舍 | 容纳数量增加，产出频率提升 |

---

### 3.5 动物系统 (Animal)

**动物分类**：
| 类型 | 示例 | 产出 | 需要设施 |
|------|------|------|----------|
| 家禽 | 鸡、鸭 | 鸡蛋、鸭蛋、羽毛 | 鸡舍/鸭棚 |
| 水产 | 鱼 | 可捞取 | 鱼塘 |
| 宠物 | 猫、狗 | 无直接产出 | 无 |

**行为**：
- 家禽白天在设施周围随机走动，晚上自动回窝
- 鱼在池塘内游动，点击鱼塘捞鱼
- 猫狗在院子自由漫步

**喂食系统**：
- 家禽每天喂一次（点击设施自动消耗饲料）
- 饲料来源：杂草/谷物 → 饲料槽自动转化
- 1天不喂：不产出但不受损
- 连续2-3天不喂：产出周期延长
- 不会死亡、不会生病、不会离开
- 后期可建"自动喂食槽"减少日常操作
- 鱼不需要喂，猫狗不需要喂

**产出规则**：
- 家禽每隔固定天数产出（鸡每2天产蛋）
- 设施等级影响容纳数量
- 产出物出现在设施旁，手动拾取

**获取方式**：来客交易换取幼崽，或达成里程碑解锁

**宠物特殊互动（后期美术到位后）**：
- 猫：偶尔叼来小东西（低频随机）
- 狗：偶尔刨出埋藏物

---

### 3.6 制作加工系统 (Crafting)

**核心逻辑**：材料 + 设施 + 时间 → 成品

**流程**：
1. 点击设施 → 配方列表
2. 选配方 → 检查材料
3. 确认 → 消耗材料，开始计时
4. 时间到 → 成品出现在设施上，手动拾取

**设施与配方对应**：
| 设施 | 类别 | 示例 |
|------|------|------|
| 灶台 | 熟食、糕点 | 桂花糕、蛋炒饭 |
| 晾晒架 | 干货 | 桂花干、萝卜干 |
| 石磨 | 粉类 | 糯米粉、小麦粉 |
| 腌制缸 | 腌渍品 | 泡菜、酱菜 |
| 工作台 | 手工物件 | 竹篮、花环 |

**资源层级严格不超过3层**：
```
基础资源(直接获取) → 中间材料(一次加工) → 最终成品(二次加工)
```

**配方获取方式**：
| 途径 | 说明 |
|------|------|
| 问妈 | 院子里有电话/信箱，每天可问一次，妈妈教你家传做法（附带温馨对话） |
| 邻居教你 | 来访NPC聊天时传授 |
| 自己试 | 设施有"自由组合"槽位，试对了学会配方，试错了材料消耗、产出失败品 |
| 翻老物件 | 开荒/扩建时偶尔发现"奶奶的食谱本" |

**自由组合失败处理**：
- 材料消耗，产出失败品（黑暗料理、焦糊物等）
- 失败品可丢堆肥箱变肥料，或给狗吃
- 不想浪费就走"问妈"等稳妥路线

**设计原则**：
- 不设失败率
- 不设品质等级
- 一个设施同时只做一件，多个同类设施可并行

### 3.7 来客与订单系统 (Visitor)

**来客类型**：
| 类型 | 频率 | 行为 |
|------|------|------|
| 邻居 | 高频 | 串门聊天、偶尔教配方、带小礼物 |
| 货郎 | 每3-5天 | 卖种子、幼崽、材料、图纸 |
| 求购客 | 每2-4天 | 带具体需求，完成后给奖励 |
| 稀有访客 | 低频（条件触发） | 独特配方、稀有种子 |

**订单机制**：
- 求购客头顶显示需求气泡
- 有货直接交付 → 获奖励
- 没货 → 订单保留1-3天
- 超时 → 订单消失，无惩罚
- 可直接拒绝，无负面后果

**奖励**：铜板、稀有种子、配方、特殊材料

**来客频率驱动（院子吸引力）**：
- 来客质量和频率由院子发展程度决定（设施数+作物种类+动物种类+装饰物数量）
- 系统后台统计达到阈值自动触发新类型来客
- 玩家感知："院子变好了，来串门的人多了"

**院门开关**：
- 关门 = 当天不来客
- 开门 = 正常
- 关门不会错过限时内容，稀有访客改天再来
- 完全由玩家掌控社交节奏

---

### 3.8 里程碑与扩建系统 (Milestone & Expansion)

**里程碑**：
| 类别 | 示例 |
|------|------|
| 种植 | 第一次收获、种满5种作物 |
| 建造 | 第一间正经房子、拥有3种设施 |
| 制作 | 第一份桂花糕、掌握10种配方 |
| 动物 | 第一只鸡、集齐多种动物 |
| 来客 | 完成首笔订单、累计交易20次 |
| 院子 | 第一次扩建 |

**里程碑表现**：
- 完成时屏幕边缘轻提示（不弹窗打断）
- 日记本/相册界面查看所有成就
- 奖励自动进入背包或解锁列表

**扩建**：
| 要素 | 设计 |
|------|------|
| 触发条件 | 达成特定里程碑 |
| 成本 | 大量基础材料 |
| 过程 | 确认后立即解锁（扩建是奖励时刻） |
| 新区域 | 全部未开荒，需逐步清理 |
| 区域特色 | 北面有水域、南面日照好、西面大树桩 |

### 4.4 关键技术点

**等距网格**：
- 逻辑坐标 (x,y) → 屏幕坐标转换
- Sprite 排序：`sortingOrder = -(y * mapWidth + x)` + 高度偏移
- 自行管理格子数据，不用 Unity Isometric Tilemap

**存档**：
- JulyCore Save 模块
- SavableStoreBase 序列化为 JSON
- 每天结算自动存档 + 手动存档

**配置驱动**：
- 所有数值走 Luban 表，不在代码里写死
- 美术资源路径通过配置引用，方便后续替换

## 6. MVP 范围（完整单季体验）

**选定季节：秋季**（桂花开放、果实成熟、丰收感强）

### 6.1 内容清单

**地图**：初始 12×12 + 第一次扩建区域（北面含水域）

**作物（5种）**：
| 作物 | 生长 | 用途 |
|------|------|------|
| 白菜 | 3天 | 食物 |
| 萝卜 | 5天 | 食物/晾干 |
| 糯米 | 7天 | 制作核心材料 |
| 菊花 | 5天 | 观赏/花茶 |
| 辣椒 | 5天 | 食物 |

**树木（2种）**：桂花树（秋季开花）、柿子树（秋季结果）

**动物（2种）**：鸡（产蛋）、猫（宠物）

**建筑/设施**：
- 主屋（2级）、灶台（2级）、晾晒架、石磨、鸡舍、围栏、饲料槽、仓库

**配方（8-10个）**：
- 桂花 → 晾晒 → 桂花干
- 糯米 → 石磨 → 糯米粉
- 桂花干 + 糯米粉 → 灶台 → 桂花糕
- 鸡蛋 + 辣椒 → 灶台 → 辣炒蛋
- 白菜 → 灶台 → 清炒白菜
- 萝卜 → 晾晒 → 萝卜干
- 菊花 → 晾晒 → 菊花干 → 灶台 → 菊花茶

**来客（3-4个NPC）**：1邻居 + 1货郎 + 1-2求购客

**里程碑（约10个）**：覆盖种植、建造、制作、动物、订单、扩建

### 6.2 不包含（后续版本）

- 春/夏/冬季内容
- 鸭、鱼、狗
- 高级建筑（大厨房、腌制缸等）
- 稀有访客
- 室内装饰
- 音效音乐
- 多存档槽位

## 7. 设计原则

1. **所有系统必须能在"方块+文字"级别美术下正常运行** —— 视觉表现是锦上添花
2. **Sprite 为可配置引用** —— 后续换美术只替换图片+配置，不改代码
3. **资源层级不超过3层** —— 基础→中间→成品
4. **不设惩罚性机制** —— 不死亡、不掉声望、不强制时间
5. **一个概念一个操作** —— 建造系统只有建和拆，不搞多种升级逻辑
6. **配置驱动** —— 所有数值走 Luban，不写死代码
